# 内容基座记录

这些记录支持研究和定位，不把目录条目、读过原题、归类完成和正文承载混为一个状态。

| 文件 | 权威对象 |
|---|---|
| `scope.json` | 当前范围版本、初始发现入口与待判边界 |
| `sources.json` | 来源的采用理由、实际入口、传播关系、读取范围与枚举配置 |
| `books.json` | 推荐书目、已提供状态、真实采用版与质量摘要 |
| `cases.jsonl` | 已实际研究的原题、条件、阅读记录和处理去向 |
| `patterns.jsonl` | 模式、重要变种、关联和实际正文／代码位置 |
| `query-plans.json` | 待执行的多角度查询；不是已执行搜索记录 |
| `inventory-heads.json` | 每个登记入口当前接受的目录快照 |
| `inventories/` | 历史目录元数据快照，可能包括尚未接受的候选 |

完整目录记录可以只有身份、标题与链接；没有案例读件时，默认尚未读题、尚未归类。`search --kind inventory` 查询的是当前接受的元数据，并随命中显示该区别。

当前快照从 `inventory-heads.json` 读取，不能遍历整个历史目录累加条目数。不同来源可能引用相同原题，原题身份不因镜像、多语言或多份题解而改变。元数据原页保存在本机 `.local/materials`，公开快照保留原页摘要、过滤条件、解析版本和规范化记录摘要。

首次启动中曾发现 CP 作者分类页一个 Kattis 链接尾部空格，随后按原链接核对并规范化。进一步针对原表格补齐了脚本尚未生成链接的题号和分类，当前 head 使用 `cpbook_table`；首次通用链接快照保留作历史。USACO 下一模块导航也与题目分页明确分开。历史记录中的采集结果只说明当时的工具输出，当前使用仍以校验通过的 head 为准。

采集结果有分页未处理、结构异常、访问失败或未经审阅的减项时，保留先前成功基线。模型仍需判断范围、题意、算法和真实教学承载；字段齐全和结构检查通过都不构成内容完备认证。
