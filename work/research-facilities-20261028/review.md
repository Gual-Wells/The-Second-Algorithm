# 设施与发布衔接审阅

本审阅针对研究设施工程，不是某一算法章的语义完整性评定。

## 已完成的反向检查

- 独立研究身份在正文之前成立，不能依赖 `course_snapshot` 已经存在有效课程。
- 动态账本、材料和范围与阶段快照分开；追加资料保留早期研究，不把当前变化误写成历史没发生。
- 初始范围之前，全部已知书目和站点必须有真实相关性处置，默认 pending 不算全景完成。
- 首轮综合、研究后的范围复审与再综合分别留证；范围维持允许有依据地保留，不能强迫凑增量。
- 旧分支删除需明确处置；归并环、非已分析材料、悬空题型、未决核心与不匹配练习阻止交接。
- 章合同必须承接研究的领域、分支、材料证据、题型及练习计划；独立 accepted 笔记不能旁路。
- 当前资料、关键笔记、有效基座和历史快照改变时，旧交接/准备包失效；自己的新章注册不制造循环失效。
- 已实际部署的精确交接凭匹配的部署收据及准备包保留历史基座；新增教材、来源与后续章节不迫使旧章全研究重跑。自己的研究档案、范围和笔记仍严格核验，新交接不继承豁免。
- 研究状态应保留可信历史断点，同时显示当前编辑错误；错误不得损毁最后有效状态或伪造通过。
- 载体撤回仍可诚实验证与部署，不为设施验收制造章节研究；正文、身份和私人状态保持现状。

## 实质质量边界

程序不能证明 Agent 真的深度理解、所有资料都已穷尽或代理独立性自述属实。
因此协议同时规定原始读件、方法与条件核对、反复综合、独立挑战和逐项回应，
模型必须真实执行；非空字段、阶段数和通过测试均不替代语义判断。

## 验证记录

完整验证和发布结果以本目录 README 的完成记录、任务验证收据及部署收据为准。
单独的双章节生命周期测试已通过：第二章完成真实阶段夹具、审阅、验证与准备，第一章研究文件未改，旧章历史采用与新章严格初次采用能够同时成立。
