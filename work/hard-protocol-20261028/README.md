2026-10-28。起始版本 `main@d4dd7cc0fc2027e10238542b56e197be418c0dc4`，起始工作区干净。前置研究见 [出版复盘与内容设计](../../research/2026-10-28/paradigm-led-chapter-design.md)。本轮落实协议、模型、作者装配、静态知识包和阅读交互，没有新增正式教学章，也未为旧章追认通过。

## 实际建设

### 研究与编纂职责

共同协议、研究部、章节标准、实现标准、质量工艺与恢复入口已同步。章以代表性大思想领域为单位，先恢复全材料基座和出版反馈，提取相关材料、归并思想分支/题型/变型及交叉应用，再形成题型结构。前置理论之后，正式一级节按题型从标准到复杂；证明、代码和C++支撑从属于题型。每节包含真实手写/标准设施路径及1–5份在研究期已核对的练习。

读者的计算机基础不作删内容理由，C++短板也不作降低算法高度的理由。没有整题标准库解时，展示真实设施负责的部分；不凑伪解或复制两份相同程序。跨思想组合正常讲清，后续思想章仍保有完整视角。程序不替代实际材料理解、语义归并和逐节通读。

### 合同与发布约束

`second_algorithm/chapters.py`支持合同schema2：

- `paradigm`登记共同机制、全景归并证据、主要分支及其材料/题型/交叉思想关系；证据复用现有materials权威。
- `prelude`定位思想理论前置；`reading.units`成为正式题型单位。
- 题型的八项关系定位问题、思想匹配、变型、手写/解析、标准设施/解析和工程支撑；允许合理共享锚点，不要求印八个固定栏目。
- 实际核验前置与题型H2归属、顺序、题型内部位置、真实实现身份和设施层次。不得用别节解释或无归属H2充数。
- 每节1–5份练习须来自对应任务sourceUrls，且实际出现在该节正文。

结构校验仍允许诚实open以便施工；内容质量与发布准备要求新合同、独立知识模型及当前真实采用均有效。旧schema1合同、旧显性Q模型不能借新accepted进入内容发布。原先的输入冻结、最新失败阻断、不可变准备包及部署核验保持。

现有《区间上的取舍》保留旧对象专题身份，明确记录4项未完成承诺、阅读结构缺口和needs-work。它没有被改名为贪心大章。结构可构建、代码可验证与新教学标准合格是不同状态。

### 唯一知识资产与作者装配

`catalog/learning.json`升级schema2；13份现有C++解释提取为`content/knowledge/`下的独立Markdown。内部身份不绑定原章节是否仍在书架；不复制一份新摘要作为浮窗正文。

- `[[Q…|语义术语]]`显示术语，精确段引用支持`#lifetime`等语义锚点。
- `{{knowledge:Q…}}`从同一权威装配首次解释；不进入算法题型目录，全课程最多一次首次内嵌。
- 其他引用读取相同知识资产；场景新增推理继续写在题型正文。旧解释里的“本章”和特定数值已明确为区间示例，避免误用到后来场景。
- 校验唯一源、重复解释、重复首次教学、未知知识/小节、前置环及无效标签；代码围栏、注释和行内字面示例不被展开改写。
- 作者构建固定原始文件字节SHA，包含合法UTF-8 BOM；不以归一化文本冒充原件身份。

同名算法cpp没有改动，26份权威展示区域继续同源。知识示例单独承担知识说明，不虚增算法代码区域数。

### 静态发布与读者交互

载体按实际引用、首次教学、前置及卡内引用闭包生成受保护知识JSON。未引用条目不进入该发布包；源码/知识/助手构建器变化都会使旧读件或准备失效。知识资产沿用现有library鉴权、owner隔离、版本白名单和整章离线缓存，没有新数据库、知识API、后台推理或定时任务。

正文点击术语打开现有蓝银系列弹层，隐藏内部编号，不跳走主阅读位置。支持卡内知识返回、精确段落、关闭后焦点恢复、代码选择/复制/横滚、加载失败重试与过期响应丢弃。去掉了显性编号管理入口，算法目录不再收录知识主讲。

## 实际反查与修复

1. **快速关闭后重开。** 独立复现发现旧popstate可能关闭新知识浮窗；现在待旧历史关闭完成再打开，复现与正式回归均验证。
2. **BOM与哈希。** 解析层去BOM后按文本算SHA，与原字节核验不符；改用源Buffer的SHA，并测试合法BOM和修改后的失效。
3. **旧知识模型绕过。** 新合同曾可配旧显性Q模型准备发布；质量核验现要求learning schema2，反例即使有accepted也被拒绝。
4. **精确知识锚点。** 载体曾将原始空锚点转义；现安全保留语义锚点。首次内嵌按条目命名空间处理，避免不同卡同名锚点冲突。
5. **延迟返回。** 关闭和返回时立即更新显示序号，已关闭浮窗的迟到响应不再缓存或重新填入新弹层。
