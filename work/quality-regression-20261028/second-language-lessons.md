## 3. 最有证据的回退机制

### 3.1 正式条款仍完整，实际生产工艺换了

10/24 复盘确认，协议从未允许漏独立派生词条、独有意义、原例或标签。两日使用的 Collins/Oxford 字节相同，教材读取 helper 无语义差异；同为 gpt-6.1-sol，实际档位 xhigh→max。保存记录未发现会话压缩，新运行没有被05:00完成期限催停，发布字节与本地相同。因此“教材变坏、平台降档、迁盘、压缩或运输损坏”均不是已证明原因。[S4]

直接脚本证据更具体：

- 旧 10/23 `expand-sources.mjs:7` 按实际词族执行 `lookupBooks(books,[word,...family])`；第一、二部分内容对象本来含独立 examples；`assemble-chapter.mjs:15` 只追加范文去向。
- 被撤回 10/24 `prepare-authored.mjs:8–18` 从已有混合 `source-lookups` 筛词族材料，没有对新增词族范围重查；`assemble.mjs:22` 只检查已提取集合的去向，`:35` 对无原例 USE 直接复制首个关联范文句。
- 后来真正修复为 `scripts/lib/teaching-authoring.mjs:52–59` 独立查询每个主词/词族/补查项，并在 `:75–79` 核材料摘要与每项双书查询；`:117–130` 检查内容与原例去向。注释明确不在这里自动写定义、造例或范文回填。

这不是单纯“提示不够强调”。成熟内容工艺留在忽略的旧运行临时脚本里；工程迁移了发布、存储与调度，却让新会话重造内容生产。完整规范与绿色检查覆盖不了一个从源头缩小的材料集合。[S4][S6]

### 3.2 闭环范围由自身产物定义，漏项可以自证完整

固定教材反证指出 compensatory 丢了补偿特殊困难者措施的独立用途，proportionality 丢了规范性比例原则；6个独立词头至少8条相关教材原例未进入成品。7个候选缺头中 interpretative 只是跳转，不计作漏义。这一细分防止审计把线索全部报错。[S5]

原检查的逻辑是“已抓条目→已抽原例→全部已有例均映射”，三层共享缺口。缺的是从独立确认的词族范围出发反查教材，而不是再给 lesson 的完成声明加一项勾选。对算法项目，相应风险是仅以已登记 task/method/Q/target 为全集，再证明全集都被引用和编译；登记外被省略的条件、变种或C++依赖可永远不进入检查。

### 3.3 “实事/即用”被样例和便利入口收窄

初衷包含理解科学、文化、公共变化与人的处境，也包含生活可用；落地首章却主要成了虚构社区里反复比较、核实、谨慎判断。复盘撤回了“真实来源改变人物决策，因而实事目标充分实现”的低门槛判断。默认四 feed 并非技术来源上限；实际只用了两家三份材料，反映编辑研究停在方便入口，而不是机器禁止扩大。[S1][S4]

可迁移的风险：算法章节也可能把“求职即用”窄化为常见题型模板、API速查或短代码。真实题号、引用链接、通过判题和短期方便，只各自证明有限事实；还需看读者究竟获得何种条件判断、方法推导与实现选择。

### 3.4 为完整性扩写的知识不全是必要教学负担

重做后的680 USE是实际范围，不等同680陌生词；873例主要来自原例547条与必要补例326条，不支持“例句配额普遍堆砌”。51篇没有协议硬要求，一义一新闻、一派生一场景、禁止多目标共载等也不存在。[S11]

另一方面，写前任务若从旧标题、来源、目标分组派发，即使不读旧正文也会继承旧结构；本次51/51题材起点如此。独立重写又证明放开旧组织不自动减量：新理解任务更深、更多单目标评语，变成38篇但总量+7.68%。最早保存完整稿已多849词，后续净增132词，不能主要归咎审阅返修。[S11][S12]

这支持算法审计检查“题目/方法/实现/Q被如何派发”“是否把能研究的每一支都变必修”“每段虽有用途，合起来是否超出本章任务”。不支持按文件数、题数、Q数或字数直接裁决质量。

## 4. 最终采用了什么，仍未证明什么

10/27 的研究不是宣布所有真实材料都胜出。目的抽样涉及20个旧 USE 身份：15项保留真实来源候选资格、4项回退、1项体验待定；一项只研究旧ID内材料分支。词形探针的436候选/244无候选不是语义覆盖率；15/20也不是随机成功率。独立审阅明确否决了部分“职责百科”“馆藏用途说明”，并要求指南继续给租客条件、判决继续裁定、契据继续声明权利。[S14][S15]

正式新合同落实了以下取舍：[S16][S17]

1. **义旁就地呈现。** 一份词内教学流承载核心义、必要限制、真实语境及整块译文，再补句法等；取消独立第二/第三部分，完整双书内容与真实词族仍保留。
2. **实际候选择优。** 每用法最终1–5份；3仅各份有独立收益时的甜区，单份可胜出。候选数、候选类别和检索轮数均不固定；不为共享多义选词或拉长段落。
3. **分开三项编辑判断。** 来源确有目标义且事实保真；相较旧例有真实学习增量；保留来源正在完成的语言行为。多知识、有链接、结构完整不能相互替代。
4. **诚实回退与停止。** 没有更优可用原文可以用明确的教学构造例，不能造真实故事、偷换邻义、删义或无限搜；足够好且无具体问题时收束。
5. **冻结前保护候选价值。** 口语起点是支架，不是选词上限；审取材便利、单主题、少义短小及形式难度偏置。用实际考虑过的备选与固定正式参照复核，不加比例、分数、逐词审计、固定反选数或全池重搜。
6. **工程固化语义边界的入口。** 新输入及selection显式 authoringPolicy，作者上下文必须从证据对象经唯一槽位装配；来源 readDigest 与采用原件绑定；旧冻结继续旧 protocolCommit，不混装新旧合同。

当前脚本确有独立材料包、逐义 contextChoices、多份增量说明、fallbackReason 与原件摘要核对；工程部署/后端/阅读器隔离验证记录也存在。**这些只支持生产合同与传输入口已接通。** 首份新格式正式全章尚未生产，没有整章语义、真实工时、个人水平、保持率或成本降低证明；实体 iPhone/Safari 也未由 Chromium触控仿真代替。不能把“最终采用”写成“学习问题已成功解决”。[S16]
