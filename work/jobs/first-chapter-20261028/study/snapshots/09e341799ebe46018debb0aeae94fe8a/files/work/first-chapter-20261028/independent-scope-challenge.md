# 二分领域：独立范围挑战（未见作者范围）

日期：2026-10-28。此稿在未读取整合者首轮scope、题型表或作者正文的前提下形成；本轮读取的是候选比较之后的新方法材料和新原题。它提出需要回应的挑战，不宣称完成章节审阅或替代不可变研究阶段。机器可读来源与已核题合同在同目录 `independent-scope-challenge-materials.json`。

## 独立结论

若本章声称系统处理“二分查找/有序结构与判定搜索”，至少要实质承载以下四块：

1. **多个答案共享昂贵判定**，并区分事件时间二分与值域整体分治。
2. **区间秩选择从静态到带修改**，不能把值域选择仅处理为静态矩阵计数。
3. **结构内下降/提升直接寻找边界**，包括Fenwick秩选择与线段树首次失败；纯函数跳k步则是支撑/对照，不自动属于二分。
4. **带数量限制的惩罚参数搜索**，必须说明凸性和精确恢复，不能用普通答案二分的“check单调”一笔带过。

它们都是二分机制的重要变化，不应因首章、数据结构或DP前置而只留名称。另一方面，不必把所有会用到这些工具的高级数据结构、全部凸分析、完整Aliens满分解都纳成独立主干。判断依据是本章排除证据/判定组织/参数反演是否发生实质变化，而非题目难度标签。

## 挑战A：两个“多查询二分”并不是同一个算法

### A1. 时间轴首次满足：重放一轮事件，服务一批mid

新核原题 **CSES New Roads Queries**：最初无边，每天加一条边，N/M/Q≤2×10^5，问两点首次连通日，不可达输出−1。同点的答案应为0，不能因事件从第1天开始就遗漏。这里查询谓词对时间单调，但查询数据不具备逐条贡献相加的形式。

这类问题可让每个查询维护时间边界，每轮按mid分组，重置DSU后顺序加入道路，在相应mid做连通判定。新读作者型教程Minh-Thien Nguyen《Parallel Binary Search》包含这一实现；我核了迭代代码，而没有照抄其抽象递归伪码。**含路径压缩的普通DSU不能直接撤销**；每轮重建是合法策略，若递归需要回滚则须换数据结构和证明。自推复杂度应包括N规模重置，稳妥表达为 `O((N+(M+Q)α(N)) log(M+1))`，不照搬忽略N项的简写。

关键反查：OI Wiki整体二分引入的独立/可加等条件适用于其加法统计实现，不能当作所有parallel binary search的必要条件；只增边连通性已经是反例。**共享可增量计算的判定**是更广的共同点。

### A2. 值域整体二分：拆操作集，查询携带剩余秩

新读OI Wiki正文/参考实现，并核 **洛谷P3834** 静态区间kth与 **P2617 Dynamic Rankings** 带修合同。其值域二分决定元素/更新流向；统计左半值域在当前区间的出现数，若答案流向右侧，查询秩应减去这部分数目。递归结点的秩已经是剩余秩，不是始终原始k。

独立推演的带修正确性要求：

- 初始值编码为插入事件；一次赋值必须删除**当时旧值**再插入新值。同值修改可省略，但不能把赋值误当加法。
- 同一时间序列稳定划分；在一个递归结点顺序扫描时，Fenwick记录的恰是“已经发生且落入左值域”的有符号更新。查询看到将来更新就是错误。
- 删除事件具有负贡献，**不破坏对数值阈值的单调计数**，因为每个时刻的实际多重集计数仍非负；但通常破坏“随时间越来越满足”，所以不能沿时间套A1。
- 更新和查询分别有不同分派规则。查询向右时扣秩；更新向右只改变后续递归可用事件，不做查询式秩变换。
- 进入子问题前撤销本结点施加的全部更新；不能每个结点O(N)清空整个Fenwick，必须按实际改动撤回/重置。回滚顺序需与结构合同匹配。
- 若离线压缩值域，初始和所有新值都纳入；重复值同秩，叶子映回原值。不能只压缩初始数组。

事件数 `E=N+2×修改数+查询数`，采用Fenwick的一般实现为 `O(E log U log N)`；U为离散值数。不能用“整体二分O(logU)”掩盖每层扫描与结构查询。静态专门结构（可持久化计数树、wavelet一类）可避免部分重复，但它们的完整结构课程不是本章需要承担的所有替代方案。

**范围建议**：A1与A2都保留。静态与动态kth可同一正式题型内递进，不能只有两个链接而正文省掉带修逻辑。它们共享离线批处理思想，状态不变量、单调轴和复杂度不同，应分别解释。

## 挑战B：结构内边界搜索，比“二分外套log查询”更进一步

新读KACTL作者实现：`FenwickTree::lower_bound`以二进制步长接受前缀块、扣除剩余目标；`BinaryLifting.h`分别提供固定步数跳跃与LCA。已把GitHub当前commit固定为 `b3548e973f8772010c1ef84e6d427c749733fd2c` 并下载对应原件用于本次阅读。

### B1. Fenwick第k个：维护前缀频数证书

新核 **CSES List Removals**：N≤2×10^5，每次删除当前第p个，输出原值。可保留原位置，用0/1存活频数，找前缀累计首次达到p的位置。外层普通二分＋每次Fenwick前缀查询会得到log²；结构内按块提升能做到log。

由实现独立反推的必要条件：用于秩选择的前缀量应单调（普通频数要求非负）。不能因为Fenwick支持负增量更新，就推断任意正负数组也可按前缀和lower_bound；删除使频数从1变0是合法负更新，累计数组仍单调。KACTL原码固定最高步长 `1<<25`，不能直接视为任意N的通用合同；成稿应按实际上界确定步长、空/不存在政策和索引语义，不复制宏依赖。

### B2. 线段树首次失败：摘要可以提供更一般的证书

新读 **AtCoder Library segtree::max_right/min_left** 的原始合同及 **practice2 J Segment Tree** 原题。真实库保证依赖monoid、确定且无副作用谓词、`f(e())=true`；“返回全局最远边界”的含义还依赖沿扩展区间的谓词单调。这比只看数组是否排序更一般。

practice2 J第三类查询是在允许点修改后，找指定位置右侧第一个值≥V的位置。输入数组本身不必排序，但区间最大值能判定一整块是否可以跳过。它适合作为“摘要证书驱动边界下降”的正式应用；不能把ACL说成C++标准库，亦不能假装整题有std一键算法。

### B3. 倍增预处理不等于二分查找

新核 **CSES Company Queries I** 与 **Planets Queries I**。给定精确k，按k的置位组合函数2次幂，是函数复合/倍增计算，不是在搜索未知边界；特别是有环函数图并无默认单调“祖先高度”。它能作为支撑构造，不能取代本章对“哪一跳可以接受”的证明。

相比之下，寻找仍满足某条件的最远祖先、两点同步提升直到LCA前一层、正数循环数组中的最少分段，可以在明确单调/可行性证书后纳入。新核 **CSES Cyclic Array** 规定每项正且不大于容量，支持贪心最远下一位置和跳跃；如果允许负数，原机制不能直接照搬。

**范围建议**：必须有实际边界提升/下降应用；精确k次迭代是必要支撑和反例，非强制扩大成完整树/LCA/函数图课程。

## 挑战C：WQS/拉格朗日不是“单调计数”就能精确解

新读 **IOI2016 Aliens官方题目与官方解答**。官方解答PDF物理17页已渲染核对数学关系，原题物理1和3页已渲染、3页已目视核约束；PDF文本提取会把公式数值漂移，约束以原页为准。该题官方满分方案明确列出照片数价值函数的离散凸性定理（该页没有展开完整证明），对每张加惩罚，用单调照片数搜参数；跳过目标数时利用同斜率段恢复。它还要去包含区间、处理面积交叠以及CHT，故“用WQS”不是完整解题说明。若采用Aliens作完整教学例，仍需补足该题凸性论证，不能把官方列定理误报成已经读到证明。

新读 **USACO Building a Tall Barn** 官方原题和Yang Liu官方题解：N≤1e5、K≤1e12，每层至少一头牛，目标为Σa_i/c_i；边际收益随人数递减，可对边际阈值二分计数并修正多/少分配，输出取整有0.1安全间隔。它是较小而清晰的“资源数量约束→边际阈值”实例，可以承担本章可执行交叉应用；它不意味着任意资源问题都有离散凸性。

以下是独立数学反查，不借权威名义省略推理：设原约束价值 `F(k)`，最小化时放宽为 `G(λ)=min_k(F(k)+λk)`。比较两参数的最优性不等式，可以推出选中数量随λ非增，**这个单调性并不要求F凸**。但仅有它，不代表每个目标k都能被某参数支持。

- 反例 `F(0)=0, F(1)=1, F(2)=0`：任何λ下k=1都不会最优；目标k=1的原值为1，参数解的下凸包恢复只能给0。搜到了计数分界也不能凭空把0当1。
- 相反，`F=(4,2,0)`在λ=2三个数量并列。固定“少用优先”或“多用优先”会跳过k=1，但目标点共线，`G(2)-2×1=2`可恢复。**数量不恰等于K不等于失败；无凸性支持却硬减λK才是失败。**

因此建议本章承载一维惩罚参数搜索的核心、离散凸/凹条件、同值最优时计数政策、恰好/至多的差别、参数边界和精确恢复。具体载体可采用较清楚的边际分配或小DP，不必把Aliens的全部几何和CHT都塞进同一节；但不能以“属于DP”或“太难”删掉WQS的真实机制。若选择别的教学原题，应另行真实核题与证明，不能把本报告的未读题标为已核。

### 与“较新/更广方法”的界线

本轮还读了OI Wiki当前WQS说明中共线处理、对偶及凸性部分。它进一步讨论高维乘子、对偶函数和三分/黄金分割。此类扩展提示“WQS”名称覆盖的范围并不都等同一维布尔二分。**不建议为了追新把高维凸优化和全部对偶理论纳为本章主干**：不是因难而排除，而是搜索结构从有序单参数边界变成其他优化机制。可以交代界线并留稳定入口。
