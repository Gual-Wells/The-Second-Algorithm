## 有限清单与本章的关系

| 原题 | 真正需要维护的信息 | 当前范围判断 |
|---|---|---|
| CSES3220 Sliding Window Sum | 加入与移出数值更新区间和 | 本章可直接承载；生成式输入与最终xor是原题包装。 |
| CSES3221 Sliding Window Minimum | 只保留尚未过期且不被新值支配的极值候选 | 本章单调队列分支。 |
| CSES3426 Sliding Window Xor | 同一值再次xor可消去，形成可逆聚合 | 本章可承载，与和对照；不推广为所有位运算均能消去。 |
| CSES3405 Sliding Window Or | 离开一个值后仍需知道其他值是否贡献每个bit | 暂不纳入；bit频数或一般关联聚合队列是额外结构，不能以xor或减法移除。 |
| CSES3222 Sliding Window Distinct Values | 每个值的频数及非零种类数 | 本章固定频数窗口；重复元素只在0↔1时改变种类数。 |
| CSES3224 Sliding Window Mode | 最大出现次数，次数相同时最小值 | 暂不纳入；需要动态维护频数和值的有序竞争关系，不等于只维护distinct数量。 |
| CSES3219 Sliding Window Mex | 最小缺失非负整数 | 暂不纳入；频数之外还需有效维护缺失值集合或等价结构，不能每窗从0重扫冒充线性。 |
| CSES1076 Sliding Window Median | 动态秩序统计，偶数窗选择较小中位数 | 暂不纳入；窗口本身并未解决有序分区与重复删除合同。 |
| CSES1077 Sliding Window Cost | 到某个中位数的绝对差和及两侧总量 | 暂不纳入；还需维护秩与分侧和，不能由整体sum直接得到。 |
| CSES3223 Sliding Window Inversions | 位置有序的严格逆序对；相等不计 | 暂不纳入；离开与加入涉及秩计数，不是简单频数差分。 |
| CSES3227 Sliding Window Advertisement | 每个固定窗口内部任意连续板段可承载的最大矩形面积 | 暂不纳入；不是全窗宽度乘最小值，也不能直接照抄固定极值队列。 |

这些暂不纳入的条目仍有确切身份和内容原因，并非因为题目难或为了凑一章篇幅。后续实际研究可以改变归属，当前章不宣称已经讲解这些结构。

## 会影响实现与讲解的细节

前四道生成式题（sum/min/xor/or）允许`n`达到`10^7`，原题输出是**全部窗口结果的xor**。通用返回每个窗口结果的函数可以承担机制讲解，但不是未经适配就能当作原题完整提交。生成器的乘加中间值需要64位；sum窗口聚合也可能达到`10^16`。不能因最终输出是xor就把每个窗口和压为32位。

本章使用普通数组作为接口时，应直接说明是机制参考实现；没有必要把每种LCG输入包装重复放进相邻模板。生成式原题若用于提交或性能验证，另做相应适配，不能宣称已经实测通过。

cp-algorithms正文区分了只存值、存值与下标、双栈三种最小队列。只存值且按离队值删除时，用严格`>`弹尾而保留相同值；按下标过期的实现才可以安全删除较旧的相同极值候选。参考实现宜采用下标，直接表达过期与支配的不同判断。原文的“平均O(1)”对应整段操作的摊还界，不应讲成随机输入下平均才线性。

一个自行构造的区别反例是`[2,2,3]`、窗口长2：值队列若用`>=`删掉第一个2，随后又按离队值2移除队头，会同时丢失仍应留在下一窗口的第二个2，错误返回3。用下标存储可以清楚避免这种身份混淆。这个反例是本次独立推导，尚未运行作者生产源码；应在正式实现验证时落实。
