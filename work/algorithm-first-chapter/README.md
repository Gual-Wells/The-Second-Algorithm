### 推荐交接范围

1. **连续区间的直接摘要**：明确半开区间、空前缀与非空答案合同；一维静态区间和／异或，以及固定长度聚合与频数维护。只解释会改变代码与边界的差异，不讲数组零基础。
2. **匹配历史前缀状态**：任意符号的目标和计数、余数同类、二元类别平衡；比较频数与最早位置分别回答计数和最长长度。空前缀初始化、先查后记、重数、负余数和64位累计必须真正承载。
3. **单向推进的连续边界**：无重复／至多K类、最长与计数、at-most差分得到exact；非负和条件下的阈值窗口，以及覆盖指定多重集的最短窗口。严格正数、允许零、含负数分别核对，不能拿1660的单次等和计数直接推广到零元素。
4. **最优连续段的历史摘要**：工程继续读取并研究最大段和的最小前缀／Kadane联系，保留全负数与空段是否允许；不因名字叫动态规划就要求先读完DP课程。

上面是研究问题群，不是固定小节数或代码块配额。频数表与哈希表用标准库就近解释必要合同，C++语法和容器系统知识由另一线承载，但本章不依赖任何隐藏试读才能理解。

### 暂不纳入与待定

- 不扩成一般数组百科：原地分区、排序实现、一般k-sum、全量字符串匹配、排列和抽样不纳入本次主体。二维前缀、差分批处理、离线查询与动态更新另作范围候选，不借空邻章指针声称已经讲解。
- 滑动中位数／代价、逆序数、Fenwick／线段树等不是只多一个窗口循环，暂不并入。固定窗口极值的单调队列是否应作为本章必要结构，留给下一阶段实读与范围反馈，不能仅为列齐窗口题无限加入。
- 含负数的“至少某和最短段”、长度受限最优段等可能要求新的前缀候选维护结构；尚不宣称普通窗口覆盖它们。是否应纳入本章需依据内容价值与反查证据调整。
- 题库标签与教材归类不构成排除或强套方法的理由。发现新的重要问题关系，可以改变章名、纳入边界和分稿方式。
