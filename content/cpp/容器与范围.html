容器与范围

C++ 实作 · 存储、查询、迭代与借用

同一个业务目标常常只差一个条件，就需要换接口：预留空间不等于创建元素，查询不等于默认插入，过滤不等于擦除，保存视图不等于保存数据。本篇按这些真实操作组织，代码主体为 C++17；标出 C++20／23 的部分可单独对照。

1 存储与修改

预分配后填充，还是先创建再赋值

已知要产生 n 个元素，有两种正常写法：reserve(n) 后逐项 push_back/emplace_back；或 resize(n) 后给已有下标赋值。前者 size 仍为0，不能直接写 a[0]。后者确实构造 n 个对象，类型需要支持相应构造。

inline std::vector<long long> squares(int count) {
    if (count < 0) throw std::invalid_argument("negative count");
    std::vector<long long> result;
    result.reserve(static_cast<std::size_t>(count)); // 尚无元素
    for (int i = 0; i < count; ++i) result.push_back(1LL * i * i);
    return result;
}
inline std::vector<int> zero_buffer(std::size_t count) {
    return std::vector<int>(count);                  // 已有 count 个 0
}

vector 的追加均摊 O(1)，一次扩容会移动／复制已有元素；增长倍数不是统一规定。clear() 清掉元素，通常保留容量；shrink_to_fit() 是非强制请求，不能把它当成必然释放内存的指令。

批量删除与遍历中删除

批量过滤先把保留项移到前面，再一次 erase：remove_if 本身不改变容器大小，返回新的逻辑尾部，后面的值不再具有“被删除项原样放在尾部”的保证。若必须边访问边擦除，接住 erase 返回的下一位置。

template<class T, class Predicate>
std::size_t erase_matching(std::vector<T>& values, Predicate predicate) {
    const auto old_size = values.size();
    auto new_end = std::remove_if(values.begin(), values.end(), predicate);
    values.erase(new_end, values.end());
    return old_size - values.size();
}
inline void erase_negative_one_by_one(std::vector<int>& values) {
    for (auto it = values.begin(); it != values.end();) {
        if (*it < 0) it = values.erase(it); // erase 返回有效的下一位置
        else ++it;
    }
}

对 vector 连续 erase 多个位置，最坏 O(n²)；remove＋erase 总计 O(n)。C++20 的 std::erase_if(values,predicate) 可直接完成同一批量操作。list::remove_if 则是成员函数，会实际摘掉节点。

保存位置时，分清是哪一种句柄。

修改 vector 的迭代器／引用／指针
reserve 或追加发生重分配 全部失效，包括旧 end
push_back 未重分配 原元素句柄有效，旧 end 失效
insert 未重分配 插入点之前有效，插入点及其后失效
erase 擦除点及其后失效，接住返回迭代器

需要删改时避免预先缓存 end。下标不会成为悬空指针，但插入／删除后未必还表示原来的元素。对 deque，首尾插入通常保持原元素引用，却会使迭代器失效；list 插入不使已有元素句柄失效，擦除只影响被擦除元素。不能把一张 vector 规则表直接套给其他容器。

连续接口与代理引用

把 vector／array 交给接收连续元素的接口，用 data()＋size()；空范围不要通过 &a[0] 或 front() 取得首地址，接口是否接受空指针仍以它自己的约定为准。deque／list 不是一整段连续数组。

inline std::optional<int> maximum_buffer(const int* data, std::size_t count) {
    if (count == 0) return std::nullopt; // 空范围不解引用 data
    int best = data[0];
    for (std::size_t i = 1; i < count; ++i) best = std::max(best, data[i]);
    return best;
}
inline std::optional<int> maximum_values(const std::vector<int>& values) {
    return maximum_buffer(values.data(), values.size());
}

vector<bool> 是位压缩特化，没有普通 bool[] 的地址语义。其下标返回代理，auto 可能保留对原位的访问，而非复制一个 bool。

inline bool proxy_example() {
    std::vector<bool> bits{false};
    auto alias = bits[0];       // vector<bool>::reference，仍指向原元素
    bool snapshot = bits[0];    // 真正的 bool 值
    alias = true;
    return bits[0] && !snapshot;
}

因此需要值快照时明确写 bool value = bits[i]；通用代码不能假定 decltype(a[i]) 一定是 T&。这不是“vector 不能使用任何标准算法”，而是要看具体算法和标准版本的要求。

2 查询与排序关系

统计、只读查询与有条件更新

计数用 ++counts[key] 很自然：缺失键会默认构造映射值0。但“查一下是否存在”不要顺手用 []，否则查询会改变容器。find 一次得到存在性和值；at 不插入，但缺失时抛出异常。

inline std::map<std::string, std::size_t>
frequencies(const std::vector<std::string>& words) {
    std::map<std::string, std::size_t> counts;
    for (const auto& word : words) ++counts[word]; // 缺失时构造 0
    return counts;
}
inline std::optional<int> lookup(const std::map<std::string, int>& values,
                                 const std::string& key) {
    auto it = values.find(key);                  // 不插入；一次查找
    if (it == values.end()) return std::nullopt;
    return it->second;
}
inline bool install_once(std::map<int, std::unique_ptr<int>>& values,
                         int key, std::unique_ptr<int>& candidate) {
    auto [it, inserted] = values.try_emplace(key, std::move(candidate));
    (void)it;
    return inserted; // 已有 key 时 candidate 不被移动
}
inline void replace_value(std::map<std::string, int>& values,
                          std::string key, int value) {
    values.insert_or_assign(std::move(key), value); // 缺失则插，已有则赋值
}

try_emplace 已有键时不构造映射对象，也不会把传入的 move-only 实参搬空；但参数表达式仍会先求值。若写 try_emplace(key, expensive())，expensive() 不会凭空跳过。insert_or_assign 表达的则是“已有就覆盖”。

map 的成员 find 通常 O(log n)，unordered_map 平均 O(1)、最坏 O(n)；通用 std::find(begin,end,value) 仍逐项扫描。unordered_map 的 reserve/rehash 可能使迭代器失效，但不会使仍在容器中的元素引用／指针失效；erase 的目标元素除外。

自定义哈希键与排序比较器

自定义键需要把“什么算同一个键”与哈希同时定义。相等的键必须得到相等哈希；哈希相同不代表键相等。

struct Point {
    int x, y;
    friend bool operator==(const Point& a, const Point& b) noexcept {
        return a.x == b.x && a.y == b.y;
    }
};
struct PointHash {
    std::size_t operator()(const Point& p) const noexcept {
        auto h1 = std::hash<int>{}(p.x), h2 = std::hash<int>{}(p.y);
        return h1 ^ (h2 + std::size_t{0x9e3779b9} + (h1 << 6) + (h1 >> 2));
    }
};
using PointCounts = std::unordered_map<Point, std::size_t, PointHash>;

排序比较器描述严格弱序：自身不小于自身、不能双方互相小于、严格关系有传递性，而且由双方均不小于定义的等价关系也须有传递性。不能写 a <= b；否则同一个对象会排在自己前面。下面按优先级降序、名字升序，平局自然形成等价类。

struct Job { int priority; std::string name; };
inline void order_jobs(std::vector<Job>& jobs) {
    std::sort(jobs.begin(), jobs.end(), [](const Job& a, const Job& b) {
        if (a.priority != b.priority) return a.priority > b.priority;
        return a.name < b.name; // 同优先级按名字升序
    });
}
inline void stable_priority(std::vector<Job>& jobs) {
    std::stable_sort(jobs.begin(), jobs.end(), [](const Job& a, const Job& b) {
        return a.priority > b.priority; // 同优先级保持原相对顺序
    });
}
inline bool nan_last_less(double a, double b) {
    if (std::isnan(a)) return false;
    if (std::isnan(b)) return true;
    return a < b;
}

浮点输入含NaN时，普通<不能在该集合上形成严格弱序：1与NaN不分先后，NaN与2也不分先后，但1与2却不等价。可以在入口拒绝NaN，或像nan_last_less这样把所有NaN放在最后并视作一类；不能先把违反比较前提的sort跑一遍，再将观察结果当保证。

stable_sort 的“相等”指 !comp(a,b) && !comp(b,a)，不要求 a==b。只按 priority 比较时，稳定排序才会保留同优先级记录的原顺序；加入 name 决胜后，原顺序已不是主要规则。排序 O(n log n)，比较器一次调用的成本另计。

3 范围算法

需要有序前缀，还是只要第 k 项

全部有序用 sort；只需前 k 项且这 k 项有序，用 partial_sort；只问第 k 小的值，用 nth_element。它只保证目标位置以及两侧分区，不保证左侧／右侧各自排好。

template<class T, class Compare = std::less<T>>
std::vector<T> first_k_sorted(std::vector<T> values, std::size_t k,
                               Compare compare = {}) {
    k = std::min(k, values.size());
    std::partial_sort(values.begin(), values.begin() + k, values.end(), compare);
    values.erase(values.begin() + k, values.end()); // 不额外要求 T 能默认构造
    return values;
}
inline int kth_value(std::vector<int> values, std::size_t k) {
    if (k >= values.size()) throw std::out_of_range("k"); // k 从 0 开始
    std::nth_element(values.begin(), values.begin() + k, values.end());
    return values[k]; // 左右两侧分别满足分区条件，不承诺各自有序
}

partial_sort 约 O(n log k)，未截断的后缀不承诺顺序；nth_element 串行版本平均 O(n)。两者都要求随机访问迭代器。这里复制输入以保留原数据；允许改原数组时直接在原范围调用。降序或自定义记录沿用同一个严格比较器。

有序范围上的多重集合运算

两个范围先按同一个比较器排序，再作集合运算。它们处理的是多重集合：例如 a 中三个2、b 中一个2，difference 留两个2，intersection 留一个2，union 留三个2。

template<class T, class Compare = std::less<T>>
std::vector<T> multiset_difference(const std::vector<T>& a,
                                   const std::vector<T>& b,
                                   Compare compare = {}) {
    // 前提：a、b 都按 compare 排好序；保留 max(count_a-count_b, 0) 份
    std::vector<T> result;
    std::set_difference(a.begin(), a.end(), b.begin(), b.end(),
                        std::back_inserter(result), compare);
    return result;
}

交集／并集／对称差依次换成 set_intersection/set_union/set_symmetric_difference，两边输入、输出方式与比较器保持一致，O(n+m)。结果写入新范围，不把输出位置放进正在被读的输入范围。若目标是真正去重的集合，先对输入排序＋unique，不能假装这些 API 自动去重。

单遍输入、输出位置与两种“成对”

下面两个函数都可以接流迭代器，不提前遍历统计长度。zip 的两种元素类型可以不同，以较短的一侧结束；两两分组只读一个范围，本接口明确忽略最后一个落单元素。

template<class Input1, class Input2, class Output>
Output zip_to(Input1 first1, Input1 last1, Input2 first2, Input2 last2,
              Output out) {
    using A = typename std::iterator_traits<Input1>::value_type;
    using B = typename std::iterator_traits<Input2>::value_type;
    for (; first1 != last1 && first2 != last2; ++first1, ++first2)
        *out++ = std::pair<A, B>(*first1, *first2);
    return out; // 在较短范围结束；输出空间须足够，或用 back_inserter
}
template<class Input, class Output>
Output disjoint_pairs_to(Input first, Input last, Output out) {
    using T = typename std::iterator_traits<Input>::value_type;
    while (first != last) {
        T a = *first; ++first; // 保存值，不能保存单遍输入的别名
        if (first == last) break; // 本接口选择忽略奇数末项
        T b = *first; ++first;
        *out++ = std::pair<T, T>(std::move(a), std::move(b));
    }
    return out;
}

输出是 *out++ = value：既可写预留好的数组位置，也可写 back_inserter(result)。仅有 reserve 的 vector 没有可供普通迭代器赋值的元素，不能直接把 begin 当输出缓冲。这里从输入复制元素值；需要搬走 move-only 元素时，要另行采用移动迭代器／移动策略，不能悄悄保留原输入承诺。

InputIterator 只保证单遍；forward iterator 才支持独立多遍遍历；随机访问才有常数时间 +n、last-first。即使声明了 random_access_iterator_tag，也必须真正实现其操作和复杂度。下节环形缓冲只声明它确实提供的 forward 迭代能力。

不要混淆成对定义： [1,2,3,4,5] 的不重叠分组是 (1,2),(3,4)；C++23 views::adjacent<2> 是 (1,2),(2,3),(3,4),(4,5)。

将记录投影成新值

提取成员、调用成员函数或应用 lambda，都由 std::invoke 统一处理。输出容器存值，返回引用的投影也会复制成值；需要保留引用时应明确选择其他表示，而不是误以为 vector 可以存引用。

template<class Input, class Function>
auto select_values(Input first, Input last, Function function) {
    using Result = std::decay_t<std::invoke_result_t<Function&, decltype(*first)>>;
    std::vector<Result> result;
    for (; first != last; ++first)
        result.push_back(std::invoke(function, *first));
    return result; // 返回引用也会复制成 Result；不预先遍历计算 distance
}

例如 select_values(jobs.begin(),jobs.end(),&Job::name) 得到 vector<string>；lambda 也可以返回新建的 move-only 对象。代理对象不会因 decay 自动变为它所代表的普通值；若投影返回 vector 的代理而你需要 bool，需显式转换。输入只走一遍，结果个数与输入一致，O(n) 次调用。调用参数与返回类型的进一步约束见泛型专题，避免在每个算法重讲一套模板规则。

4 借用与视图

span 传连续对象，views 延迟组合

C++20 的 span<T> 只保存一段连续对象的地址与长度，不接管元素。span<const T> 是只读元素；const span<T> 只是不能改视图对象，本来的 T 仍可写。

inline void zero_out(std::span<int> values) { // C++20，借用可写连续元素
    for (int& value : values) value = 0;
}
inline std::vector<long long> even_squares(std::span<const int> values) {
    auto selected = values
        | std::views::filter([](int x) { return x % 2 == 0; })
        | std::views::transform([](int x) { return 1LL * x * x; });
    std::vector<long long> result;
    for (auto value : selected) result.push_back(value); // 在这里求值
    return result;
}

filter／transform 不会先造一份新容器；上例在 for 循环访问时计算，再主动物化成 vector。过滤通常把随机访问范围降成最多双向／前向范围，不能继续假定支持 selected[i]。反复遍历可能重复调用投影，因此不要把有副作用的函数当作稳定缓存。

通过 filter 的迭代器修改元素时，修改后仍须满足原过滤条件；若要改变成员资格，改底层数据后重新建立／遍历合适范围。还要保留底层数据与需要的父 view 对象，不能只保存一个可能依赖父对象的迭代器。

对forward_range，filter_view会缓存第一次begin找到的位置，以满足重复begin的摊还常数复杂度要求；“惰性”不表示每次从头重新筛选。底层新增了更靠前的匹配值时，旧view不保证自动发现它；改变容器结构可能还使缓存迭代器失效。需要重新筛选时重建视图，不能把旧视图当自动更新的查询结果。

view、拥有与 borrowed_range 是三个问题

string_view 是借用的字符范围，data 不保证在视图末尾有 NUL；所有者销毁或重新分配都会让旧 view 悬空。具体的切分、裁剪和有界 API 见文本与文件。

static_assert(std::ranges::borrowed_range<std::string_view>);
static_assert(std::same_as<
    decltype(std::ranges::find(std::vector<int>{1, 2}, 2)),
    std::ranges::dangling>);
// string_view 自身销毁不移除原字符；但原字符的所有者仍必须存活。

对临时 vector 查找，ranges 返回 dangling，避免把已经销毁的容器迭代器直接交回。string_view 满足 borrowed_range，只说明视图外壳销毁不销毁字符，并不替原字符延长寿命。

“view 一定不拥有数据”也不成立：下面的 owning_view 接管临时 vector，返回后仍然拥有元素；相邻窗口返回的则仍借用传入 span。代码标 C++23，部分现代 C++20 标准库通过缺陷修正也提供 owning_view，不能据此要求所有旧 C++20 实现都支持。

inline auto owning_numbers() { // C++23；现代 C++20 库也可能通过修正提供
    return std::views::all(std::vector<int>{3, 4, 5}); // owning_view 接管 vector
}
inline auto adjacent_pairs(std::span<const int> values) {
    return values | std::views::adjacent<2>; // (0,1)、(1,2)…，不是两两分组
}

5 两种组合容器

优先处理：把决胜条件写进比较器

priority_queue 默认最大值先出；希望小优先级先出就反转比较方向。同优先级保持先来先处理，需要显式加序号，容器本身不保证稳定性。

struct Pending { int priority; std::size_t sequence; std::string payload; };
struct Later {
    bool operator()(const Pending& a, const Pending& b) const noexcept {
        return std::tie(a.priority, a.sequence) > std::tie(b.priority, b.sequence);
    }
};
using ReadyQueue = std::priority_queue<Pending, std::vector<Pending>, Later>;
// 最小 priority 最先出；相同 priority 按 sequence 从小到大。
// priority_queue 本身不为“相等优先级”保证稳定性，sequence 是显式决胜项。

push/emplace/pop O(log n)，top O(1)；pop 只删除，不返回元素，需要先读 top。若手动使用 vector＋堆算法，push_heap 不会替你追加元素，pop_heap 也不会替你缩短 vector。

最近若干项：运行时容量的覆盖式环形缓冲

适合保留最近 N 条日志／样本：未满时追加，满时覆盖最早项，pop 取最早项。它与“满时拒绝”的有界工作队列是不同接口。optional 槽位让 T 不必默认构造；本实现要求移动构造不抛异常，避免覆盖旧对象后因构造失败留下逻辑空洞。

template<class T>
class overwrite_ring {
    static_assert(std::is_nothrow_move_constructible_v<T>,
                  "this implementation requires nothrow move construction");
    std::vector<std::optional<T>> slots_;
    std::size_t head_ = 0, used_ = 0;
    const T& at_rank(std::size_t rank) const {
        return *slots_[(head_ + rank) % slots_.size()];
    }
public:
    explicit overwrite_ring(std::size_t capacity) : slots_(capacity) {
        if (capacity == 0) throw std::invalid_argument("zero capacity");
    }
    overwrite_ring(const overwrite_ring&) = default;
    overwrite_ring& operator=(const overwrite_ring& other) {
        if (this != &other) {
            overwrite_ring prepared(other);
            slots_.swap(prepared.slots_);
            std::swap(head_, prepared.head_);
            std::swap(used_, prepared.used_);
        }
        return *this;
    }
    overwrite_ring(overwrite_ring&& other) noexcept
        : slots_(std::move(other.slots_)), head_(other.head_), used_(other.used_) {
        other.slots_.clear(); other.head_ = other.used_ = 0;
    }
    overwrite_ring& operator=(overwrite_ring&& other) noexcept {
        if (this != &other) {
            slots_ = std::move(other.slots_); head_ = other.head_; used_ = other.used_;
            other.slots_.clear(); other.head_ = other.used_ = 0;
        }
        return *this;
    }
    std::size_t size() const noexcept { return used_; }
    std::size_t capacity() const noexcept { return slots_.size(); }
    bool empty() const noexcept { return used_ == 0; }
    void push(T value) {
        if (slots_.empty()) throw std::logic_error("moved-from ring");
        const auto index = (head_ + used_) % capacity();
        slots_[index].emplace(std::move(value));
        if (used_ == capacity()) head_ = (head_ + 1) % capacity();
        else ++used_;
    }
    std::optional<T> pop() {
        if (empty()) return std::nullopt;
        std::optional<T> result(std::move(*slots_[head_]));
        slots_[head_].reset();
        head_ = (head_ + 1) % capacity(); --used_;
        return result;
    }
    void clear() noexcept {
        for (auto& slot : slots_) slot.reset();
        head_ = used_ = 0;
    }
    class const_iterator {
        const overwrite_ring* owner_ = nullptr;
        std::size_t rank_ = 0;
    public:
        using iterator_category = std::forward_iterator_tag;
        using value_type = T;
        using difference_type = std::ptrdiff_t;
        using reference = const T&;
        using pointer = const T*;
        const_iterator() = default;
        const_iterator(const overwrite_ring* owner, std::size_t rank)
            : owner_(owner), rank_(rank) {}
        reference operator*() const { return owner_->at_rank(rank_); }
        pointer operator->() const { return std::addressof(**this); }
        const_iterator& operator++() { ++rank_; return *this; }
        const_iterator operator++(int) { auto old = *this; ++*this; return old; }
        friend bool operator==(const const_iterator& a, const const_iterator& b) {
            return a.owner_ == b.owner_ && a.rank_ == b.rank_;
        }
        friend bool operator!=(const const_iterator& a, const const_iterator& b) {
            return !(a == b);
        }
    };
    const_iterator begin() const { return {this, 0}; }
    const_iterator end() const { return {this, used_}; }
    // 所有修改操作都使本实现原有迭代器失效；只提供只读 forward 迭代。
};

push/pop O(1)，clear O(capacity)，按逻辑先后顺序只读迭代。本实现任意修改都使已有迭代器失效，不承诺标准容器的稳定性。容量0在构造时拒绝；移动后源对象为空且容量0，可查询、clear、赋值，push 会抛出异常。复制操作需要 T 可复制；移动路径也支持 unique_ptr 一类对象。

复制赋值先构造完整副本，再无异常地交换槽位和下标，避免元素复制中途抛出后破坏二者的对应关系。nothrow move只保证这里的移动路径，不能推导出复制也不抛异常；不能因此把赋值机械设为default。
