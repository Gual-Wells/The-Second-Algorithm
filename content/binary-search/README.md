本版已完成一次发现、原题/教材核对、归并、独立反查、修订、代码对照和阅读检查。**尚未封为范围完备版**：14项明确进阶/接口缺口及21条未取得原题保留在记录中；不能把已写条目全通过理解成整个二分专题零遗漏。具体结论和继续工作的入口见[全流程研究](../../research/2026-10-26/binary-full-cycle.md)。

`*.source.md`是作者稿，`*.cpp`是代码权威；可读MD/HTML由同一源码装配。C++主体为C++17，组合稿中较大乘积采用GCC/Clang的`__int128`扩展。

```sh
npm install --ignore-scripts
npm run build:binary
python -m unittest discover -s tests -v
python -m second_algorithm validate
```

构建需要Node20以上及锁定的marked17.0.5；研究CLI和离线结构校验只需Python3.11以上。阅读HTML自身不需要这些依赖，也不会联网加载脚本或字体。
