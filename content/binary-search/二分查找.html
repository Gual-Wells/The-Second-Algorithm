二分题先分清：查位置、利用特殊结构排除一半、二分答案、用计数找第 k 小。它们共用折半过程，真正需要区分的是每次凭什么保留一侧。复杂目标的实际判定放在组合判定，动态定位与批量查询见进阶扩展。

下标从 0 开始，ll 为 long long；“有序”默认非降，允许相等。代码采用 C++17，完整函数见 二分查找.cpp。

单调边界的两个外壳

首真对应 false…false,true…true；末真反向。下面闭区间内保证有解，找不到解的题先检查极端值，或按题意另设虚拟端点。r=m保留m时取下中点，l=m保留m时取上中点，才能保证区间缩短。

template<class F>
ll first_true(ll l, ll r, F can) { // 闭区间 [l,r] 内保证有解；r-l 可用 ll 表示
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (can(m)) r = m;
        else l = m + 1;
    }
    return l;
}
template<class F>
ll last_true(ll l, ll r, F can) { // 闭区间 [l,r] 内保证有解；r-l 可用 ll 表示
    while (l < r) {
        ll d = r - l;
        ll m = l + d / 2 + d % 2; // 向上取整，但不计算 d+1
        if (can(m)) l = m;
        else r = m - 1;
    }
    return l;
}

每次判定花 T，则总时耗 O(T log R)。局部峰不需要全局单调谓词，依靠另一种排除证明，见2.3。标准库二分需要按比较关系分区，不必所有元素互异；降序或按记录字段查找时，排序与比较关系必须一致。链表上的lower_bound只有比较次数为对数，迭代器移动仍可能线性。

1 有序边界与有序状态

1.1 查值、插入位置、首末位置

把“找一个 x”统一为找边界。 lower_index 找首个 ≥x 的位置，upper_index 找首个 >x 的位置；找不到就返回 n。两者只差一个等号。

遇到 a[m]≥x，m 仍可能是左边界，令 r=m；否则 m 及其左侧都不是答案，令 l=m+1。

int lower_index(const vector<int>& a, int x) {
    int l = 0, r = (int)a.size();
    while (l < r) {
        int m = l + (r - l) / 2;
        if (a[m] >= x) r = m;
        else l = m + 1;
    }
    return l;
}
int upper_index(const vector<int>& a, int x) {
    int l = 0, r = (int)a.size();
    while (l < r) {
        int m = l + (r - l) / 2;
        if (a[m] > x) r = m;
        else l = m + 1;
    }
    return l;
}

记 L=lower_index(a,x)、R=upper_index(a,x)。例如 a=[1,2,2,2,5]、x=2，得到 L=1,R=4，相等元素恰好占据 [L,R)。

要求 直接对应
查找 x／查首个 x L<n && a[L]==x 时返回 L，否则不存在
x 的首末位置 L<R 时为 [L,R-1]，否则不存在
x 的出现次数 R-L
严格小于 x 的最后位置／不大于 x 的最后位置 L-1／R-1；-1 表示不存在
大于等于 x／严格大于 x 的首个位置 L／R；n 表示不存在
值域 [u,v] 内的元素个数，u≤v upper_index(a,v)-lower_index(a,u)
最接近 x 的元素 只需比较合法的 L、L-1 两个候选，距离用 ll

稠密排名先排序并unique，再取lower_bound+1；若要统计严格较小的原元素数量，则必须保留重复，直接取lower_bound下标。不要把这两种排名混用。

标准库对应 lower_bound、upper_bound；返回的是迭代器，减去 a.begin() 得下标。求严格大于直接用 upper_bound，无需构造 x+1。

能二分计数，不代表总目标单调。 例如UVa12965的成本是生产者报价>x的数量 + 消费者报价<x的数量，前者下降、后者上升，总成本不能直接二分。应枚举价格0及相关断点，用上下界加速每次计数。

同型变种： 第一个坏版本、首次达标位置，本质是找首个使 check(m) 为真的位置，把代码里的 a[m]>=x 换成 check(m) 即可。循环字符中的“下一个更大字符”用右边界，结果为 n 时回到下标 0。

1.2 第 k 个缺失正数

给定严格递增的正数数组，求未出现的第 k 个正数。到下标 i 为止，应有 a[i] 个正数，实际出现 i+1 个，所以缺失数为 a[i]-i-1，它随 i 不减。

找首个“缺失数至少 k”的下标 i，答案为 i+k；如果所有位置都不足 k 个，i=n，公式仍成立。

ll kth_missing_positive(const vector<int>& a, ll k) {
    int l = 0, r = (int)a.size();
    while (l < r) {
        int m = l + (r - l) / 2;
        if ((ll)a[m] - m - 1 >= k) r = m;
        else l = m + 1;
    }
    return l + k;
}

例如 [2,3,4,7,11] 的缺失累计为 [1,1,1,3,6]。第 5 个缺失数落在下标 4 对应的间隙中，答案为 4+5=9。查找 O(log n)。

1.3 最接近 x 的 k 个数

有序数组中选 k 个最近元素，距离相同时优先较小值。答案可取一个长度为 k 的连续窗口，二分的是窗口左端，不是某个元素。

左端为 m 和 m+1 的两窗口只更换两个端点：移走 a[m]、加入 a[m+k]。若 x-a[m] > a[m+k]-x，窗口应向右；否则保留左侧，平局也留左。这里保留带符号的差值。

int closest_window_left(const vector<int>& a, int k, int x) {
    int l = 0, r = (int)a.size() - k;
    while (l < r) {
        int m = l + (r - l) / 2;
        if ((ll)x - a[m] > (ll)a[m + k] - x) l = m + 1;
        else r = m;
    }
    return l;  // 选取 a[l .. l+k-1]
}

要求 1≤k≤n。左端查找 O(log(n-k+1))，实际输出 k 个元素再花 O(k)。题型原型：LeetCode 658。

1.4 值等于索引：隐式有序差值

递增且互异的整数数组，求a[i]==i。相邻值至少增加1，所以a[i]-i非降；找首个a[i]>=i的位置再核对是否相等。下面返回首个固定点，空数组或没有固定点返回−1。O(log n)。

int fixed_point_distinct(const vector<int>& a) {
    int l = 0, r = (int)a.size();
    while (l < r) {
        int m = l + (r - l) / 2;
        if ((ll)a[m] >= m) r = m;
        else l = m + 1;
    }
    return l < (int)a.size() && a[l] == l ? l : -1;
}

允许重复后差值不再单调，例如[0,0]的差值是[0,-1]。此时可递归剪枝到左侧[l,min(mid-1,a[mid])]和右侧[max(mid+1,a[mid]),r]，但最坏O(n)，不能继续承诺一次排除半边。

1.5 字符串的字典序前缀范围

输入已按字典序排序。把每项只比较到前缀长度，所得序列仍非降；两次边界得到完整匹配半开区间[first,last)，没有匹配时两端相等。空前缀匹配全部字符串；无需假定只含小写字母，也不依赖“末字符加一”。比较代价计入后为O(|prefix| log n)。

pair<int, int> prefix_range(const vector<string>& words, string_view prefix) {
    auto part = [&](int i) { return string_view(words[i]).substr(0, prefix.size()); };
    int l = 0, r = (int)words.size();
    while (l < r) {
        int m = l + (r - l) / 2;
        if (part(m) < prefix) l = m + 1;
        else r = m;
    }
    int first = l;
    r = (int)words.size();
    while (l < r) {
        int m = l + (r - l) / 2;
        if (part(m) <= prefix) l = m + 1;
        else r = m;
    }
    return {first, l};
}

LC1268只要字典序最小的至多3个建议，可从first取到min(first+3,last)。如果只问是否存在，也可一次lower_bound(prefix)后检查首候选的前缀。

1.6 H-index：引用数与剩余项数的交点

引用次数已非降排序。位置i之后有n-i篇论文；citations[i]>=n-i意味着这些论文都能支撑H值n-i。左边引用数非降、右边需求递减，因此找首个满足的位置，返回n-i；无满足项时返回0。O(log n)。

int h_index_sorted(const vector<int>& citations) {
    int n = (int)citations.size(), l = 0, r = n;
    while (l < r) {
        int m = l + (r - l) / 2;
        if (citations[m] >= n - m) r = m;
        else l = m + 1;
    }
    return n - l;
}

未排序输入先排序为O(n log n)，也可用计数桶O(n)；它们是同目标的其他输入条件，不能把排序成本藏进二分的O(log n)。

1.7 前缀和、预算与最短子段

非负数的前缀和非降，零值会造成重复，仍可以二分。sum[k]表示前k项之和：达到目标找lower_bound；预算内最大项数找upper_bound(budget)-1。累计和用long long，且总和应在其范围内。

“原顺序前缀”与“任意选元素使数量最多”是两个目标。后一种先取最便宜的元素：任意k项之和都不小于排序后前k项之和，因此先排序建立成本前缀再查询。即使原题叫subsequence，这里只求数量、无相邻约束，选出的索引仍能按原序排列成子序列。排序O(n log n)，每个预算O(log n)。

vector<ll> prefix_sums(const vector<int>& a) {
    vector<ll> sum(a.size() + 1, 0);
    for (int i = 0; i < (int)a.size(); ++i) sum[i + 1] = sum[i] + a[i];
    return sum;
}

// sum[0]=0，原数组非负。找最早使前k项和>=target的k；不存在返回-1。
int first_prefix_at_least(const vector<ll>& sum, ll target) {
    auto it = lower_bound(sum.begin(), sum.end(), target);
    return it == sum.end() ? -1 : (int)(it - sum.begin());
}

// 可任意选元素，只最大化数量：先排序生成最小成本的各长度前缀。
vector<ll> sorted_cost_prefix(vector<int> costs) {
    sort(costs.begin(), costs.end());
    return prefix_sums(costs);
}

// costs非负，budget>=0；等于预算也能取，所以用upper_bound。
int max_items_with_budget(const vector<ll>& sorted_sum, ll budget) {
    return (int)(upper_bound(sorted_sum.begin(), sorted_sum.end(), budget)
                 - sorted_sum.begin()) - 1;
}

最短连续子数组和至少target。 固定左端l，找最早的右前缀sum[r]>=sum[l]+target，长度为r-l。下面允许零、要求target>0，无解返回0；O(n log n)。同一非负条件下双指针可做到O(n)。若含负数，前缀和失去有序性，这两种简单写法都不能照用。

int min_nonnegative_subarray_len(const vector<int>& a, ll target) {
    vector<ll> sum = prefix_sums(a);
    int n = (int)a.size(), answer = n + 1;
    for (int l = 0; l < n; ++l) {
        auto it = lower_bound(sum.begin() + l + 1, sum.end(), sum[l] + target);
        if (it != sum.end()) answer = min(answer, (int)(it - sum.begin()) - l);
    }
    return answer == n + 1 ? 0 : answer;
}

1.8 LIS：在最小结尾状态上二分

tail[k]表示目前长度为k+1的递增子序列能达到的最小结尾。较小结尾更容易接后续值，所以对新值x找到首个>=x的位置替换，或追加到末尾。严格递增用lower_bound；允许相等接续的非降子序列改用upper_bound。O(n log n)，空间O(n)。

int lis_length(const vector<int>& a, bool non_decreasing = false) {
    vector<int> tail;
    for (int x : a) {
        auto it = non_decreasing ? upper_bound(tail.begin(), tail.end(), x)
                                 : lower_bound(tail.begin(), tail.end(), x);
        if (it == tail.end()) tail.push_back(x);
        else *it = x;
    }
    return (int)tail.size();
}

tail记录的是不同长度各自的最优结尾，它本身不一定是原数组的一条子序列。要恢复一条真实方案，另存各长度当前结尾的索引，以及每个元素当时接上的前驱；最后沿前驱回溯。下面返回原数组索引，严格／非降规则与上面一致，不承诺字典序最小等额外条件。

vector<int> lis_indices(const vector<int>& a, bool non_decreasing = false) {
    vector<int> tail, end_index, previous(a.size(), -1);
    for (int i = 0; i < (int)a.size(); ++i) {
        auto it = non_decreasing ? upper_bound(tail.begin(), tail.end(), a[i])
                                 : lower_bound(tail.begin(), tail.end(), a[i]);
        int k = (int)(it - tail.begin());
        if (k > 0) previous[i] = end_index[k - 1];
        if (it == tail.end()) {
            tail.push_back(a[i]);
            end_index.push_back(i);
        } else {
            *it = a[i];
            end_index[k] = i;
        }
    }
    vector<int> answer;
    for (int i = end_index.empty() ? -1 : end_index.back(); i != -1; i = previous[i])
        answer.push_back(i);
    reverse(answer.begin(), answer.end());
    return answer;
}

LIS数量、最大权重等目标不能仅把tail数值改一改；它们需要保留额外状态，归DP／数据结构专题。这里承载“最小结尾状态有序，二分加速定位”这一组合。

1.9 出现位置表：反复匹配子序列

固定源串、多次短查询。把每个字符的出现位置升序存起来；查询下一字符时，二分首个严格大于上次匹配位置的位置。最早选择为后续留下最多空间，因此得到字典序最小的匹配位置序列，也满足UVa10567最小起点、再最小终点的要求。预处理O(n)，一次查询O(|q| log n)。

using Positions = array<vector<int>, 256>;

Positions build_positions(string_view source) {
    Positions pos;
    for (int i = 0; i < (int)source.size(); ++i)
        pos[(unsigned char)source[i]].push_back(i);
    return pos;
}

optional<vector<int>> subsequence_positions(const Positions& pos, string_view query) {
    vector<int> chosen;
    int last = -1;
    for (unsigned char c : query) {
        const auto& positions = pos[c];
        auto it = upper_bound(positions.begin(), positions.end(), last);
        if (it == positions.end()) return nullopt;
        chosen.push_back(last = *it);
    }
    return chosen;
}

接口按字节字符工作，覆盖原题的52个大小写ASCII字母；返回nullopt表示无法匹配，空查询返回空索引序列。若采用next表，更多空间可换取O(|q|)查询。

1.10 分层累计：先定位块，再定位块内数字

UVa10706 Number Sequence的每个Sk都是十进制1,2,…,k顺次拼接，整个序列为S1S2S3…。查询从1开始的第i个字符，i<=2147483647，不能直接构造到第i个字符。

令digit_prefix[k]是1..k的总位数，也就是Sk长度；block_prefix[k]再累加各Sk的长度。先在第二层找首个累计长度>=i的块k，扣掉前k−1块；再在第一层找块内所属数字，扣掉此前数字长度，取相应十进制位。长度累计用64位，两个查询都是lower_bound，边界相等时仍属于当前块／数字。

// Sk是十进制1..k的拼接，整个序列为S1S2S3...；位置从1开始。
struct NestedDigitSequence {
    vector<ll> digit_prefix{0}, block_prefix{0};

    // 1<=max_position<=2147483647，构建到足以覆盖该位置。
    explicit NestedDigitSequence(ll max_position = 2147483647LL) {
        int width = 1, next_power = 10;
        for (int k = 1; block_prefix.back() < max_position; ++k) {
            if (k == next_power) { ++width; next_power *= 10; }
            digit_prefix.push_back(digit_prefix.back() + width);
            block_prefix.push_back(block_prefix.back() + digit_prefix.back());
        }
    }

    char at(ll position) const { // 1<=position<=构建时的max_position
        auto block = lower_bound(block_prefix.begin() + 1, block_prefix.end(), position);
        int k = (int)(block - block_prefix.begin());
        ll inside = position - block_prefix[k - 1];
        auto end = digit_prefix.begin() + k + 1;
        auto found = lower_bound(digit_prefix.begin() + 1, end, inside);
        int number = (int)(found - digit_prefix.begin());
        int offset = (int)(inside - digit_prefix[number - 1] - 1);
        return to_string(number)[offset];
    }
};

构建到覆盖最大查询位置的K即可，预处理O(K)、空间O(K)，每次两次二分O(log K)，另加输出数字的十进制转换成本。例如总序列的第8位是2；S10中1到9之后才是数字10，需要同时保留组边界和数字位数变化。

2 特殊数组

2.1 旋转数组的最小值

比较 a[m] 与 a[r]：前者大，说明跨过了旋转处，最小值在右侧；前者小，最小值在含 m 的左侧。相等时无法辨别，但右端有可替代值，可以删去右端。

int rotated_min_index(const vector<int>& a) {
    int l = 0, r = (int)a.size() - 1;
    while (l < r) {
        int m = l + (r - l) / 2;
        if (a[m] > a[r]) l = m + 1;
        else if (a[m] < a[r]) r = m;
        else --r;
    }
    return l;
}

非空数组；无重复时 O(log n)，允许重复时最坏 O(n)。返回某个最小值位置，不保证是真正的旋转断点：[0,0,1,0] 可返回 0，而下降发生在下标 3。

2.2 旋转数组中查找 x

先辨认哪半段有序，再判断 x 是否落在这半段的值域中。 左半有序用 a[l]≤a[m] 判断；否则右半有序。唯一需要额外处理的是左、中、右三值相等：此时先缩掉两端。

int rotated_search(const vector<int>& a, int x) {
    int l = 0, r = (int)a.size() - 1;
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (a[m] == x) return m;
        if (a[l] == a[m] && a[m] == a[r]) {
            ++l; --r;
        } else if (a[l] <= a[m]) {           // 左半有序
            if (a[l] <= x && x < a[m]) r = m - 1;
            else l = m + 1;
        } else {                            // 右半有序
            if (a[m] < x && x <= a[r]) l = m + 1;
            else r = m - 1;
        }
    }
    return -1;
}

返回任一命中下标，不存在返回 -1。无重复时 O(log n)，有重复时最坏 O(n)；无重复版本可以省掉“三点相等”的分支。

2.3 局部峰与山脉数组

局部峰： 找任意一个比相邻元素大的位置。要求相邻元素不等，数组两端外视为负无穷。中点向右上坡，右侧必有峰；向右下坡，含中点的左侧必有峰。保留的是“至少存在一个峰”的半边。

int peak_index(const vector<int>& a) {
    int l = 0, r = (int)a.size() - 1;
    while (l < r) {
        int m = l + (r - l) / 2;
        if (a[m] < a[m + 1]) l = m + 1;
        else r = m;
    }
    return l;
}

O(log n)。多峰数组的坡向并非全局单调，不能把这个理由误写成“坡度是单调谓词”。

山脉中查值： 严格先升后降时，先找峰，再分别在上升段、下降段查找。下降段用 greater<int>() 作为比较器；先查上升段可优先返回较小下标。

int mountain_search(const vector<int>& a, int x) {
    int p = peak_index(a);
    auto it = lower_bound(a.begin(), a.begin() + p + 1, x);
    if (it != a.begin() + p + 1 && *it == x)
        return (int)(it - a.begin());
    it = lower_bound(a.begin() + p + 1, a.end(), x, greater<int>());
    return it != a.end() && *it == x ? (int)(it - a.begin()) : -1;
}

局部峰的坡向不必全局单调；这里证明的是保留的半边仍存在峰。山脉接口若限制读取次数，需要缓存并计数；本节vector版本不处理接口调用次数。

2.4 成对数组中的唯一单次值

有序数组中恰好一个值出现一次，其他值各出现两次。单次值之前，各对从偶数下标开始；之后配对错位。 m^1 在同一组偶／奇下标间切换：配对仍相等，唯一值就在右边；否则保留左边。

int single_unpaired(const vector<int>& a) {
    int l = 0, r = (int)a.size() - 1;
    while (l < r) {
        int m = l + (r - l) / 2;
        if (a[m] == a[m ^ 1]) l = m + 1;
        else r = m;
    }
    return a[l];
}

非空、奇数长度，返回唯一值，O(log n)。

2.5 二维局部峰

非空矩形矩阵，求一个不小于四邻居的局部峰，外边界视为更小；矩阵无须行列有序。中列取全局最大，已经保证上下方向不更大；左右若有更大邻居，沿该方向的半矩阵仍有峰，否则直接返回。每轮扫描一列并折半列数，O(rows log cols)，空间O(1)。

pair<int, int> peak2d(const vector<vector<int>>& a) {
    int rows = (int)a.size(), cols = (int)a[0].size();
    int l = 0, r = cols - 1;
    while (l <= r) {
        int m = l + (r - l) / 2, row = 0;
        for (int i = 1; i < rows; ++i)
            if (a[i][m] > a[row][m]) row = i;
        if (m > 0 && a[row][m - 1] > a[row][m]) r = m - 1;
        else if (m + 1 < cols && a[row][m + 1] > a[row][m]) l = m + 1;
        else return {row, m};
    }
    return {-1, -1};
}

一般输入返回非严格峰；若像LC1901那样相邻不等，返回的就是严格峰。中列“某个局部峰”不能替代整列最大，后者才控制上下邻居并支撑整半矩阵的排除。转置角色可得O(cols log rows)。

3 多个有序序列

3.1 搜索矩阵：先分清有序条件

矩阵满足的条件 搜索办法 复杂度
行优先展开后整体有序 把位置映射为一维下标，再二分 O(log(mn))
只有每一行内部有序 逐行二分 O(m log n)
每行、每列都有序 从右上角作阶梯搜索 O(m+n)

整体有序：虚拟展平

不必复制数组。一维下标 p 对应矩阵中的 a[p/cols][p%cols]。

bool flat_matrix_search(const vector<vector<int>>& a, int x) {
    int rows = (int)a.size(), cols = (int)a[0].size();
    ll l = 0, r = (ll)rows * cols;
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (a[m / cols][m % cols] >= x) r = m;
        else l = m + 1;
    }
    return l < (ll)rows * cols && a[l / cols][l % cols] == x;
}

仅各行有序：逐行搜索

行与行之间没有顺序保证，不能把整张矩阵直接展平后搜索。

bool row_matrix_search(const vector<vector<int>>& a, int x) {
    for (const auto& row : a)
        if (binary_search(row.begin(), row.end(), x)) return true;
    return false;
}

行列均有序：阶梯搜索

右上角 a[i][j]>x，这一列下面都更大，整列排除；a[i][j]<x，这一行左侧都更小，整行排除。它不是折半搜索，但应当和矩阵二分放在一起区分。

bool matrix_staircase(const vector<vector<int>>& a, int x) {
    int i = 0, j = (int)a[0].size() - 1;
    while (i < (int)a.size() && j >= 0) {
        if (a[i][j] == x) return true;
        if (a[i][j] > x) --j;
        else ++i;
    }
    return false;
}

展平与阶梯模板均要求矩阵非空且为矩形。

3.2 两个有序数组的第 k 小与中位数

不合并数组，二分“左半部分从第一个数组拿几个”。 两数组左半合计取 k 个：a 取 i 个，b 取 j=k-i 个。只要左边最大值不超过右边最小值，左半最大值就是第 k 小。

a： ... al | ar ...    左边取 i 个
b： ... bl | br ...    左边取 k-i 个
合格切分：al ≤ br 且 bl ≤ ar

在较短的 a 中搜索。al>br 表示 a 左侧取多了；bl>ar 表示 a 左侧取少了。空边界用负／正无穷表示。

ll kth_two_sorted(const vector<int>& a, const vector<int>& b, int k) {
    if (a.size() > b.size()) return kth_two_sorted(b, a, k);
    int m = (int)a.size(), n = (int)b.size();
    int l = max(0, k - n), r = min(k, m);
    while (true) {
        int i = l + (r - l) / 2, j = k - i;
        ll al = i ? a[i - 1] : numeric_limits<ll>::lowest();
        ll ar = i < m ? a[i] : numeric_limits<ll>::max();
        ll bl = j ? b[j - 1] : numeric_limits<ll>::lowest();
        ll br = j < n ? b[j] : numeric_limits<ll>::max();
        if (al > br) r = i - 1;        // a 左侧取多了
        else if (bl > ar) l = i + 1;   // a 左侧取少了
        else return max(al, bl);
    }
}

k 从 1 开始，满足 1≤k≤m+n，重复值按重数算；复杂度 O(log(min(m,n)+1))。中位数是总长 N 中第 (N+1)/2 与 (N+2)/2 小的均值，奇偶长度可统一写：

int N = (int)(a.size() + b.size());
double median = 0.5 * (kth_two_sorted(a, b, (N + 1) / 2)
                    + kth_two_sorted(a, b, (N + 2) / 2));

3.3 值域内的最大正方形

UVa12192 Grapevine给各行、各列均非降的矩阵，rows,cols<=500，至多10^4个查询，每次求所有格子都在[L,U]内的最大连续正方形边长，L<=U。

一块正方形的最小值在左上、最大值在右下。对每行，只需把左上角放在首个>=L的列：更靠左不合格，更靠右只会让右下值更大、剩余列数更少。全局已有边长best时，只尝试扩大到best+1、best+2……，用右下角<=U检查即可；失败后换下一行。best只增不减，整个查询成功扩张至多min(rows,cols)次，不必每行再二分边长。

// 非空矩形，各行各列非降；求全部元素都在[low,high]的最大正方形边长。
int largest_square_in_range(const vector<vector<int>>& a, int low, int high) {
    int rows = (int)a.size(), cols = (int)a[0].size(), best = 0;
    for (int r = 0; r < rows; ++r) {
        int c = (int)(lower_bound(a[r].begin(), a[r].end(), low) - a[r].begin());
        while (r + best < rows && c + best < cols && a[r + best][c + best] <= high)
            ++best;
    }
    return best;
}

每查询O(rows log(cols+1)+min(rows,cols))，额外空间O(1)。没有合格格子时返回0。这个两角判定依赖行列同时非降，只有各行有序不能照搬。

4 二分答案

把“最优值是多少”改问“答案限定为 x 时能不能完成”。 先写判定，再看可行性方向，最后确定二分边界。

目标 可行性随 x 的变化 保留方式
最小可行值，如容量、速度、时间 不可行 → 可行 可行则 r=m，否则 l=m+1
最大可行值，如最小间距最大化 可行 → 不可行 可行则 l=m，否则 r=m-1；中点向上取整

以下模板直接展开二分循环。总复杂度为“判定一次的代价 × log(答案范围)”，涉及排序时另加排序代价。

4.1 连续分段，使最大段和最小

题型： 非负数组按原顺序分为 k 个非空连续段，最小化最大段和。按序装船、分配连续书页是同一结构。

固定每段容量 cap，从左尽量装满，只有再放一个就超限时才开新段，由此得到所需的最少段数。容量越大，段数越少。二分区间为 [max(a),sum(a)]，找首个使段数 ≤k 的容量。

int segments_needed(const vector<int>& a, ll cap) {
    int count = 1;
    ll sum = 0;
    for (int x : a) {
        if (sum + x > cap) { ++count; sum = x; }
        else sum += x;
    }
    return count;
}
ll min_split_cap(const vector<int>& a, int k) {
    ll l = *max_element(a.begin(), a.end());
    ll r = accumulate(a.begin(), a.end(), 0LL);
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (segments_needed(a, m) <= k) r = m;
        else l = m + 1;
    }
    return l;
}

要求 1≤k≤n。虽然判定用的是“至多 k 段”，非负数组仍可继续拆段，得到恰好 k 段；允许负数时，这个贪心判定不再成立。题型原型：LeetCode 410。

4.2 选 k 个位置，使最小间距最大

题型： 放置设备、球、牛等，使任意相邻已选位置的最小间距尽量大。

位置排序后，固定间距 gap，先放最左位置，以后总放在第一个满足间距的位置，这样给后续保留最多空间。能放满 k 个就可行；间距越大越难，求最后一个可行值。

bool can_place(const vector<int>& pos, int k, ll gap) {
    int count = 1;
    ll last = pos[0];
    for (int i = 1; i < (int)pos.size(); ++i) {
        if ((ll)pos[i] - last >= gap) {
            last = pos[i];
            if (++count == k) return true;
        }
    }
    return false;
}
ll max_min_gap(vector<int> pos, int k) {
    sort(pos.begin(), pos.end());
    ll l = 0, r = (ll)pos.back() - pos.front();
    while (l < r) {
        ll m = l + (r - l + 1) / 2;    // 向上取中点
        if (can_place(pos, k, m)) l = m;
        else r = m - 1;
    }
    return l;
}

要求 2≤k≤n。闭区间上使用 l=m 保留中点时，中点向上取整，避免只剩两个候选时不推进。

4.3 按元素累计：速度、切割与拆袋

这三类都遍历数组求和，区别在于求的是耗时、产出，还是操作次数。

题型 单项贡献 判定 目标
每项分别处理，速度为 v ceil(a[i]/v) 总耗时 ≤H 最小 v
每根切为整数长度 L floor(a[i]/L) 总段数 ≥k 最大 L
将每袋拆到不超过 x ceil(a[i]/x)-1 总拆分次数 ≤预算 最小 x

最小处理速度／最小除数

每项都单独向上取整。正整数可写为 (a[i]-1)/v+1。例如两项 [3,3]、速度 2，耗时为 2+2=4，不是先合并后算 ceil(6/2)=3。

ll min_rate(const vector<int>& a, ll hours) {
    auto can = [&](ll rate) {
        ll used = 0;
        for (int x : a) used += (x - 1) / rate + 1;
        return used <= hours;
    };
    ll l = 1, r = *max_element(a.begin(), a.end());
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (can(m)) r = m;
        else l = m + 1;
    }
    return l;
}

a 为非空正数数组，H≥n 才有解；上界 max(a) 使每项恰需 1 个时间单位。

最大整数切割长度

长为 a 的一根材料最多切出 a/L 段，余料丢弃。下面找“第一个不可行长度”再减一，可统一处理完全切不出正长度的情况。

ll max_piece(const vector<int>& a, ll k) {
    auto can = [&](ll length) {
        ll count = 0;
        for (int x : a) count += x / length;
        return count >= k;
    };
    ll l = 1, r = (ll)*max_element(a.begin(), a.end()) + 1;
    while (l < r) {                    // 找第一个不可行长度
        ll m = l + (r - l) / 2;
        if (can(m)) l = m + 1;
        else r = m;
    }
    return l - 1;                      // 无可行正长度时为 0
}

a 为非空正整数长度，k>0；答案为 0 表示无法切出 k 段正整数长度。

限次拆袋，使最大袋最小

一袋装 a 个，最终至少分为 ceil(a/x) 袋；从一袋变成这么多袋，需要少一次拆分，即 (a-1)/x。

ll min_bag_limit(const vector<int>& a, ll operations) {
    auto can = [&](ll limit) {
        ll used = 0;
        for (int x : a) used += (x - 1) / limit;
        return used <= operations;
    };
    ll l = 1, r = *max_element(a.begin(), a.end());
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (can(m)) r = m;
        else l = m + 1;
    }
    return l;
}

a 为非空正数数组，预算非负；上界为 max(a)，对应不拆分。

4.4 多机器并行生产，求最短时间

每台机器生产一件分别需要 time[i]，同时独立工作。给定总时间 t，产出为 Σfloor(t/time[i])。这次是相同时间里累计并行产出，与上一类累计各项处理时长不同。

ll min_production_time(const vector<int>& times, ll target) {
    auto can = [&](ll time) {
        ll count = 0;
        for (int t : times) {
            count += time / t;
            if (count >= target) return true;
        }
        return false;
    };
    ll l = 1, r = (ll)*min_element(times.begin(), times.end()) * target;
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (can(m)) r = m;
        else l = m + 1;
    }
    return l;
}

机器耗时、目标均为正。最快机器独自完成全部目标的时间可作上界；模板按该上界不超过 10^18 使用。

4.5 连续相邻成束，求最早日期

每个位置在某日后可用，每束需要 size 个连续位置，位置不能重用。固定日期后扫描：遇到未开放位置就断开；连续凑满一束就计数并清空这段累计。仅数已开放总数不够，还要保留相邻关系。

int min_bloom_day(const vector<int>& days, int bouquets, int size) {
    if ((ll)bouquets * size > (ll)days.size()) return -1;
    auto can = [&](int day) {
        int run = 0, count = 0;
        for (int d : days) {
            if (d > day) run = 0;
            else if (++run == size) { run = 0; ++count; }
        }
        return count >= bouquets;
    };
    int l = *min_element(days.begin(), days.end());
    int r = *max_element(days.begin(), days.end());
    while (l < r) {
        int m = l + (r - l) / 2;
        if (can(m)) r = m;
        else l = m + 1;
    }
    return l;
}

日期、束数、每束大小均为正；所需总位置超过 n，直接无解。题型原型：LeetCode 1482。

5 排名转计数

集合不适合直接生成或排序，但可以计算 C(x)=不超过 x 的元素数 时，第 k 小就是首个满足 C(x)≥k 的 x。重复值仍按元素个数计算，计数可能一次跳过 k，所以判定不是 C(x)==k。

5.1 行列有序矩阵的第 k 小

从右上角统计：当前值 ≤x，它左侧整行前缀的 j+1 个元素都可计入，再往下一行；否则向左移动。一次计数 O(m+n)，再在矩阵最小值与最大值之间二分。

ll matrix_le_count(const vector<vector<int>>& a, ll x) {
    ll count = 0;
    int i = 0, j = (int)a[0].size() - 1;
    while (i < (int)a.size() && j >= 0) {
        if (a[i][j] <= x) { count += j + 1; ++i; }
        else --j;
    }
    return count;
}
ll kth_matrix_value(const vector<vector<int>>& a, ll k) {
    ll l = a[0][0], r = a.back().back();
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (matrix_le_count(a, m) >= k) r = m;
        else l = m + 1;
    }
    return l;
}

矩阵非空，行列均非降；1≤k≤m×n。这里二分的是值域，不是把矩阵展开后的下标。

5.2 乘法表的第 k 小

第 i 行是 i,2i,...,cols*i，其中不超过 x 的数有 min(cols,x/i) 个。逐行累计即可，不需要真的生成整张乘法表。

ll multiplication_le_count(int rows, int cols, ll x) {
    ll count = 0;
    for (ll i = 1; i <= rows; ++i) count += min((ll)cols, x / i);
    return count;
}
ll kth_multiplication_value(int rows, int cols, ll k) {
    if (rows > cols) swap(rows, cols);
    ll l = 1, r = (ll)rows * cols;
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (multiplication_le_count(rows, cols, m) >= k) r = m;
        else l = m + 1;
    }
    return l;
}

行列均为正，1≤k≤rows×cols；先交换维度，让每次计数只遍历较小的一维。

5.3 所有数对距离的第 k 小

数组排序后，固定距离 d，双指针统计差值不超过 d 的数对。右端为 r 时，把左端移到首个满足差值的位置 l，便有 r-l 对；每个 i<j 的数对恰好计一次。

ll pair_distance_count(const vector<int>& a, ll d) {
    ll count = 0;
    int l = 0;
    for (int r = 0; r < (int)a.size(); ++r) {
        while ((ll)a[r] - a[l] > d) ++l;
        count += r - l;
    }
    return count;
}
ll kth_pair_distance(vector<int> a, ll k) {
    sort(a.begin(), a.end());
    ll l = 0, r = (ll)a.back() - a.front();
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (pair_distance_count(a, m) >= k) r = m;
        else l = m + 1;
    }
    return l;
}

要求 n≥2、1≤k≤n(n-1)/2，相等元素也产生距离 0；一次计数 O(n)，总复杂度 O(n log n+n log V)。题型原型：LeetCode 719。

6 数值二分

6.1 整数平方根与完全平方数

求 floor(sqrt(x))，等价于找最大的整数 m 使 m²≤x。判断改为 m≤x/m，避免计算大整数平方。循环取上中点；只有进入循环才会使用 m，因此 x=0 时也不发生除零。

ll integer_sqrt(ll x) {
    ll l = 0, r = min(x, 3037000499LL); // sqrt(LLONG_MAX) 向下取整
    while (l < r) {
        ll m = l + (r - l + 1) / 2;
        if (m <= x / m) l = m;
        else r = m - 1;
    }
    return l;
}

模板范围 0≤x≤LLONG_MAX。若还要判断完全平方数，令 s=integer_sqrt(x)，再核对 s*s==x。三角数逆问题同理：例如n<=2^31-1时，最大完整阶数可用last_true(0,n,[&](ll k){return k*(k+1)/2<=n;})，乘法先在64位中计算。

6.2 可行上界未知：先倍增，再二分

适用条件：非负整数范围内，可行性由假变真。先试 1,2,4,8,...，找到可行上界后再查首真；如果存在接口或数值上限，就在 cap 停止。

template<class F>
ll expand_first(ll cap, F can) {
    ll r = 1;
    while (r < cap && !can(r)) r = r > cap / 2 ? cap : r * 2;
    if (!can(r)) return cap + 1;
    ll l = 0;
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (can(m)) r = m;
        else l = m + 1;
    }
    return l;
}

模板取 1≤cap<LLONG_MAX；[0,cap] 内无解返回 cap+1，倍增在乘2前检查上限。未知长度数组也可用同样办法扩展查找上界，读取范围外的约定由题目接口决定。不能假设所有判定最终都会为真。

未知长度 reader

有序reader按索引访问，越界返回nullopt。依次试0、1、3、7……，直到读到>=target或越界，再在最后区间内二分。越界在大小比较中当作+∞，无需先算总长度。index_cap限定可搜索的最大索引且必须非负；默认是long long最大值。两阶段各为对数级访问，实际用时还乘单次reader成本。

// read(i)返回optional<ll>；nullopt代表越界，合法值按索引非降。
template<class Reader>
optional<ll> unknown_lower_index(Reader read, ll target, ll index_cap = LLONG_MAX) {
    auto value = read(0);
    if (!value) return nullopt;
    if (*value >= target) return 0;
    ll l = 0, r = 0;
    while (r < index_cap) {
        l = r + 1;
        r = r >= (index_cap - 1) / 2 ? index_cap : 2 * r + 1;
        value = read(r);
        if (!value || *value >= target) break;
    }
    if (value && *value < target) return nullopt;
    while (l < r) {
        ll m = l + (r - l) / 2;
        value = read(m);
        if (!value || *value >= target) r = m;
        else l = m + 1;
    }
    return read(l) ? optional<ll>(l) : nullopt;
}

template<class Reader>
optional<ll> search_unknown(Reader read, ll target, ll index_cap = LLONG_MAX) {
    auto index = unknown_lower_index(read, target, index_cap);
    return index && *read(*index) == target ? index : nullopt;
}

unknown_lower_index返回首个有效且不小于target的位置，search_unknown再核对相等；数组可空，可含重复。使用有效标志，避免把合法最大值混成越界哨兵。

6.3 实数边界与连续函数求根

实数最小可行值

仍要求可行性由假变真，初始右端必须可行。实数没有“加一格”，因此用 l=m、r=m；固定迭代次数结束，返回可行的右端。

template<class F>
double real_first(double l, double r, F can) {
    for (int i = 0; i < 80; ++i) {
        double m = l + (r - l) / 2;
        if (can(m)) r = m;
        else l = m;
    }
    return r;
}

例如实数切绳的最大可行长度，方向反过来：可行则 l=m，否则 r=m，最终返回 l。迭代轮数按初始区间和精度选择；80 轮是常用写法，仍受浮点精度限制。

连续函数的一个根

连续函数两端异号时，区间内至少有一个根。中点与左端同号，就丢掉左半；否则丢掉右半。这里依靠连续性和异号，不要求函数单调。

template<class F>
double bracket_root(double l, double r, F f) {
    double fl = f(l), fr = f(r);
    if (fl == 0) return l;
    if (fr == 0) return r;
    for (int i = 0; i < 80; ++i) {
        double m = l + (r - l) / 2, fm = f(m);
        if (fm == 0) return m;
        if ((fl < 0) == (fm < 0)) { l = m; fl = fm; }
        else r = m;
    }
    return l + (r - l) / 2;
}

两端之一为零也直接返回。可能存在多个根，模板只保证找到其中一个；端点同号不能据此判断区间内无根。两种实数模板均要求初始区间宽度有限。

先确定函数定义域，再找夹根区间。 UVa1753的实际速度为s[i]+c，求sum(d[i]/(s[i]+c))=t，所以必须有c>-min(s)；不能因读数可负就把c限制为非负。函数在此开区间严格递减，选有限左端使函数高于t，再扩张右端使其低于t，交给夹根模板。

UVa11881的IRR也有开域：r>-1，净现值为CF[0]+sum(CF[i]/(1+r)^i)。该题初始现金流负、以后均正，因此函数严格递减且根唯一；左端不能直接取-1。若改成任意正负现金流，唯一根的结论就不能沿用。
