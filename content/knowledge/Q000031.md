# 排序比较器怎样表达顺序，而不制造错误

`std::sort(first,last,comp)` 用 `comp(a,b)` 回答“a是否严格排在b之前”。区间示例常用lambda写一个就近的比较函数：`[](const Interval& a, const Interval& b) { return a.start < b.start; }`。`[]` 表示不捕获外部变量；事件比较器中的 `[policy]` 按值保存这一政策，函数体可以读取这份副本。参数用const引用读取，见 [[Q000029|参数借用、复制与寿命]]；写成 `const auto&` 的泛型lambda让编译器从传入元素推导参数类型，区间示例仍然比较同一种事件值。

比较器必须形成严格弱序：对象不能严格小于自己；前后关系应可传递；被比较器视为等价的关系也应可传递。把 `<` 写成 `<=` 会让相等对象也“小于自己”，违背要求。若要“起点升序，同起点终点降序”，应先比较起点，不同时返回起点比较；相同才返回终点的反向比较。两项完全相同可以互不排在对方前面。

不要写 `a.start-b.start < 0`。减法可能先溢出，直接比较不需要承担这种风险。`sort` 不保证比较器等价元素保持原顺序；只有确实需要稳定性时才用 `stable_sort`。区间示例多解允许任意合法顺序的地方，不靠偶然排序次序制造唯一答案。[C++17草案的排序要求](https://www.open-std.org/jtc1/sc22/wg21/docs/papers/2017/n4659.pdf)见 `[alg.sorting]` 与 `[sort]`。
