# 怎样把参考函数组成真实的平台提交

`#include` 引入设施的声明：`<vector>`、`<queue>`、`<set>` 分别提供对应容器；`<algorithm>` 提供排序、边界与堆算法；`<functional>` 提供greater；`<utility>` 提供pair和swap；`<iostream>` 提供区间示例CSES入口使用的输入输出流。不要靠另一头文件恰好间接引入而省略所需头文件。`std::` 表明名字来自标准库；自定义命名空间的限定见 [[Q000027|聚合初始化与结果值]]。

CSES交付的是完整程序，需要一个全局 `int main()`。`std::cin >> n >> k` 按顺序读到两个已声明变量，`std::cout << value << '\n'` 写出值并换行。`for(auto& movie : movies)` 用可修改引用逐个填入端点，与 [[Q000029|参数借用、复制与寿命]] 的只读循环区别在于这里确实要写元素。输入按原题合法合同读取，区间示例入口没有损坏输入的恢复协议。

LeetCode交付的是 `class Solution` 中指定的public成员，平台负责创建对象和调用，没有自己再写main。适配器把平台的二维int数组转成核心Interval，调用后按平台要求返回数量、数组或收益；二维vector的每一行仍是一个vector，`row[0]` 等下标由原题固定列数保证合法。转换数值前先用 [[Q000032|运算类型与数值范围]] 的原题上界判断是否安全。

区间示例的完整参考文件保留全部核心函数，末尾通过 `#if defined(...)` 等条件编译选一个入口。要提交Movie Festival II，可在整份文件开头定义 `INTERVAL_MOVIE_II`；Projects定义 `INTERVAL_PROJECTS`；酒店定义 `INTERVAL_ROOMS`；LC1235定义 `INTERVAL_LC1235`。每次只选一个入口。命令行也可用 `-DINTERVAL_MOVIE_II` 并启用 `-std=c++17`。这些选择只控制哪一个平台入口参加编译，不改变核心函数；从正文只复制某一局部区域，还须带上它依赖的类型、工具和函数。
