# 怎样把端点和结果组成有名字的值

`struct Interval { long long start, end; };` 定义一种有两个成员的类型。`Interval{1, 4}` 按成员声明顺序初始化出一个值；`range.start` 取其起点。把它写进 `std::vector<Interval>`，每个元素就是一份区间值，不再靠“第0列一定是起点”的默契。这里的简单结构没有用户自定义构造函数，可以采用这种聚合初始化。

`Allocation{rooms, room_for}` 把房数与分配数组一起返回；`CoverResult{false, {}}` 把“无解”和空方案组合成一个清楚的结果。布尔状态与方案内容各有意义，调用者不能仅看空数组判断失败，因为有些任务的空输入本来就有空答案。

`enum class EndpointPolicy { HalfOpen, Closed };` 定义一个独立类型。调用时写 `EndpointPolicy::Closed`，避免把记不住含义的 `true` 当作公共政策。它不会自动替算法选择比较符号，区间示例的兼容函数才落实这条规则。代码置于 `interval_decisions` 命名空间中；外部可写 `interval_decisions::Interval` 明确名字来自哪里。C++17规则参见WG21公开草案[N4659，聚合初始化与枚举声明](https://www.open-std.org/jtc1/sc22/wg21/docs/papers/2017/n4659.pdf)。
