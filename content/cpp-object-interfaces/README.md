[阅读正文](对象如何传递.html) · [Markdown](对象如何传递.md) · [权威源码](对象如何传递.cpp)

本章以值、独占与借用的实际接口为主线，包含普通值成员、参数责任、独占资源交接、具有独立内容的缓冲区、复制移动与异常提交、view和getter的借用期限；共享拥有只承担条件保留、弱观察及必要的控制块边界。代码以C++17为主体。

题型和机制范围由[研究目标](../../work/cpp-first-chapter/README.md)及实际材料形成；该记录保留候选比较、范围变化与独立反查回流，不进入阅读正文。它不要求读者先看旧试稿。

本章不展开完整多态、泛型元编程、allocator、协程、线程同步、文件持久化或自制标准库。后续新证据若影响本章接口正确性，仍可修订范围与内容。

源码与作者稿是单一内容权威，阅读版由现有构建器装配。实际验证见[验证摘要](../../work/cpp-first-chapter/verification.json)，包括正常／边界、真实分配失败提交与独立正负编译探针；没有执行悬垂或其他UB来猜结果。
