# 连续片段：前缀状态与滑动边界

求职算法总册 · 题型与 C++ 模板

面对子数组或子串，先看**需要怎样的区间，以及条件改变后哪些历史信息仍有用**。同样有两个下标，可能是在做固定长度更新、单调窗口、匹配历史前缀，或淘汰已被支配的候选；它们的成立理由不同。

| 条件与目标 | 方法与核心状态 |
|---|---|
| 静态区间和／异或，多次查询 | 前缀差／前缀异或；保存边界摘要 |
| 固定长度的和、频数、覆盖 | 移入一个、移出一个；维护当前状态 |
| 任意正负，目标和的数量／最长／最短 | 匹配历史前缀；保存频数／最早／最近位置 |
| 无重复、至多K类 | 单向移动合法边界；频数或最近位置 |
| 非负和的上界／下界 | 利用和的方向性；维护当前和 |
| 多重集覆盖、替换预算、正整数乘积 | 分别维护缺额／最大频数／乘积 |
| 任意正负，最大连续段和 | 最小历史前缀／Kadane；一个最优摘要 |
| 固定极值、含负数的最短阈值段 | 单调队列；未过期且未被支配的候选 |

以下为C++17。区间统一写作`[l,r)`；代码使用`vector<int>`，n与n+1均能用`int`表示，累计、答案和前缀差使用`long long`。需要满足相应中间值可表示的数值范围；哈希方法的O(n)指通常的期望复杂度，最坏情况另计。字符串示例按字节处理，256计数不是Unicode码点分词。

## 1. 已给定区间：保留摘要，不反复求和

### 区间和：空前缀消掉左端特判

令`p[i]`为前i项之和，`p[0]=0`，则`[l,r)`的和为`p[r]-p[l]`。原数组允许负数；负数不会破坏这个等式。预处理O(n)、单次查询O(1)、空间O(n)，查询要求`0<=l<=r<=n`。

{{prefix-sum}}

例如`a={2,-1,3}`的前缀为`{0,2,1,4}`，`[1,3)`得到`4-2=2`。前缀下标表示元素间的位置，长度为`r-l`；原题若使用1-based闭区间`[a,b]`，对应这里的`[a-1,b)`。前缀差可以计算空区间，但后面的子数组计数仍只数非空段。

### 异或也可消去相同前缀，最小值和OR却不行

相同位模式异或两次会抵消，因此区间异或用`p[r]^p[l]`。这里显式转为unsigned位模式。

{{prefix-xor}}

不能照着把前缀最小值“相减”得到区间最小值；前缀OR也无法知道某个位来自被移除部分还是保留部分。能否消去旧状态，是决定所需结构的条件。

### 固定长度的和：只维护当前窗口

若只顺序处理所有长度k的窗口，不必保留整份前缀：加入新元素，移除`r-k`，第k项到达后输出。负数、零均可使用，因为窗口长度固定，不根据和决定移动方向。

{{fixed-sum}}

时间O(n)，除输出外额外空间O(1)。`k<=0`或`k>n`时没有合法的正长度窗口，返回空列表。固定窗口异或把加减都换为异或即可。

## 2. 固定窗口的频数：同一边界可维护多个状态

### 不同值数量：频数降到0才真正离开

用`unordered_map`支持稀疏或较大的值域。删除旧元素时不能直接删键，窗口里可能还有相同值；计数变为0后才擦除。

{{fixed-distinct}}

时间期望O(n)，除输出外空间O(min(k,d))，d为值域中实际出现的不同值数。小而确定的值域可改数组；“元素值可能到10^9”不适合按最大值直接开表。

### 固定长度、互异、最大和是状态组合

窗口边界仍由k决定，同时维护和与频数。长度为k时，恰有k种值就等价于互异；满足后更新最优和，不需要为每一种条件组合发明新的移动规则。

{{fixed-composition}}

这里用`optional`区分无合法窗口与合法的负数答案。若题目保证正数并规定无解输出0，可将无值转换为0；不能把一般有符号版本的初始最优值直接设为0。

### 异位词位置：需要的是每种字符的数量

模式串给出所需多重集。`need[ch]`表示还缺多少个该字符，负值表示多了；`missing`记录总缺额。长度相等时，总缺额为0便得到一个异位词窗口。

{{fixed-anagrams}}

加入字符时，新的`need`仍非负才补上一个缺额；移出字符后`need>0`才新产生缺额。例如模式`aab`需要两个a，仅看“含a和b”会误判。时间O(n+m)，计数空间固定；本接口对空模式返回空列表。

## 3. 任意正负的目标关系：匹配历史前缀

### 目标和的数量：找`p[r]-target`出现过几次

`p[r]-p[l]=target`改写为`p[l]=p[r]-target`。处理右端时，只在此前的前缀中查询这个状态；一份频数能一次计入多个左端，而不是每次重新扫描。

{{prefix-count}}

`frequency[0]=1`使从第0项开始的段能被找到。**先查、后记录当前前缀**保证`l<r`；若反过来，target为0时会把当前前缀与自己配对，额外数入空段。`{0,0}`的非空零和段共有3个，也说明同一前缀状态的重数不能丢。

### 同一匹配关系，最长留最早，最短留最近

目标从数量改为长度，查询的键不变，保存的信息却变了。固定右端r，最早的l使`r-l`最大，最近的l使它最小。

{{prefix-position}}

最长版本用`emplace`保留首次位置，最短版本覆盖最近位置；都在查询以后更新。两个函数以0表示没有非空解。时间期望O(n)，空间O(n)。只记一个位置无法替代频数来统计数量。

### 整除与余数：把精确和值换成同类状态

段和能被m整除，当且仅当两端前缀和具有相同的规范化余数。C++的负数`%`可能得到负余数，应转到`[0,m)`后再作为键。m须为正。

{{remainder-state}}

若m较小，可以用长度m的数组；上面用哈希只保存出现过的类。不要将不同状态碰巧拥有相同哈希值理解为同类，相等性仍由键决定。

### 两类数量相等：将一类记成-1

二元数组中把0视作-1、1视作+1，数量相等就成为段和为0。要求最长，因此保存每个balance的最早位置。

{{balance-state}}

推广时先写清状态表示什么：两类数量差、奇偶次数或余数关系可能都能成为前缀状态，但不是只要出现“数量相等”就机械套整数和。这里的函数合同只接受0、1。

## 4. 可变窗口：合法左端能否连续移动

### 最长无重复段：左端不能倒退

新值上次出现在窗口内时，将左端越过它；出现在旧窗口以前时不影响当前窗口。因此更新是`max(left,last+1)`，而不是无条件改成上次位置加一。

{{longest-distinct}}

在`{1,2,2,1}`中遇到最后的1，不能把已经右移的left退回去。每个位置处理一次，时间期望O(n)、空间O(d)。字符串的同型题可把键改为字节或字符编码。

若元素**严格为正**，改求变长互异段的最大和，仍沿用这个合法left：先用本章的`p=prefix_sum(a)`，将长度更新换成64位的`best=max(best,p[r+1]-p[left])`即可。正数保证固定右端时，最左合法起点的和最大；这是状态与目标的组合，不是另一种移动外壳。[Maximum Erasure Value](https://leetcode.com/problems/maximum-erasure-value/)就是此合同。含负数时不能这样改，例如`{-5,1}`的最长合法段和为-4，最优和却是1。

### 至多K类：一个右端贡献一段左端

加入右端后，若种类太多就收缩；直到`[left,r]`合法。此时所有`[l,r]`，`left<=l<=r`也合法，更早的左端不合法。因此当前右端的贡献是`r-left+1`，同一边界还可求最长长度。

{{at-most-distinct}}

恰好K类并不满足同样的“收缩仍合法”：少删一个可能是K类，多删一个就变为K-1类。用`F(K)-F(K-1)`统计恰好K类，F表示至多的数量。两次线性扫描仍为期望O(n)；K<=0时非空答案为0。

### 非负和计数：允许零时仍要保存所有合法起点

当元素非负时，扩大右端不会使和减小，移走左端不会使和增大。可按“和至多limit”维护合法左端，并用两个上界计数之差得到精确和。

{{nonnegative-sum-count}}

这个写法同时承载正数和零。严格正数的精确和，在固定右端时最多有一个左端；一旦允许零，该简化不再成立。例如`{0,0}`、target=0需要数3段，而不是每个右端只加1。含负数时，先前和过大的左端以后可能重新有用，改用上一节的历史前缀匹配。

### 非负和最短段：达到下界以后继续收缩

这次目标是最短且和至少target。窗口达到下界时先记录，再不断删左端；一旦不满足，等待新的右端。每个元素至多进入与离开一次。

{{nonnegative-shortest}}

时间O(n)、额外空间O(1)，0表示无非空解。对非空非负数组，target<=0时最短长度为1。**不能把它直接用于负数**：`{1,-1,5}`、target=5中，普通窗口会在删掉1后因和降到4而停止，漏掉后面的单元素5；第6节给出这种条件下的真正替代结构。

## 5. 合法性由不同状态决定的窗口

### 最短覆盖：满足以后收缩，缺额重现就停止

覆盖指定多重集与无重复是不同条件。`missing==0`表示每个必需字符都够了；此时逐步收缩，直到移走了一个仍有需求的字符。

{{minimum-cover}}

长度并不固定，所以覆盖窗口可以有多余字符。代码返回最短内容，无解或空模式返回空串；时间O(n+m)、计数空间固定。模式含重复字符时仍按重数覆盖，不能将总需求改成不同字符种类而沿用同一更新条件。

### 替换预算：窗口长度减去最大频数

把窗口全部变成同一个字母，应保留最多的那种，其余都替换；成本是`length-max_frequency`。这里针对大写字母，每次用26项扫描得到**当前窗口的真实最大频数**。

{{replacement-budget}}

时间O(26n)，固定字母表下仍为O(n)。另一种常见最长答案技巧只维护历史最大频数，它不保证当前窗口实时合法；不能把该历史值直接拿去枚举合法区间或作为每次收缩后的真实证书。上面的版本选择明确的实时合同。

### 正整数乘积严格小于K：先保证能乘，再相乘

元素至少为1时，扩大窗口不会使乘积变小；K<=1时没有合法非空段。需要严格小于K，所以使用整数上界`K-1`。当参数较宽时，不能先把乘法溢出，再试图通过收缩补救。

{{positive-product}}

`product > (K-1)/value`在相乘前判断是否超界。单个新元素已经过大时丢弃这次窗口并重启；其余情况下乘积一直不超过K-1。每个元素至多移出一次，时间O(n)、空间O(1)。本节合同是严格正整数，不包含零或负数乘积。

## 6. 最优段与支配候选：保留真正可能变优的历史

### 最大段和：每个右端减去最小历史前缀

任意符号都可用`p[r]-p[l]`。固定r，要让差最大，只需此前最小的前缀，不必枚举所有l。先比较答案，再用当前前缀更新最小值，保持非空段。

{{maximum-prefix}}

返回和及半开区间；空数组没有非空答案，返回无值。同和允许返回其中一个最优段。初始化为0会让全负数组错误选择空段；`{-5,-2,-7}`的非空最优值应是-2。

### Kadane：以当前位置结尾，是延长还是重新开始

若上一段结尾的最优和已经小于0，接上它不如从当前元素重启；否则延长。`ending`和全局最优是两份不同状态。

{{maximum-kadane}}

两种实现均为O(n)时间、O(1)额外空间，且能保留答案边界。前缀视角在后续增加限制时更容易看出“还允许使用哪些左端”；Kadane的短实现不能不加判断地推广到任意长度限制或多段约束。

### 固定窗口极值：后来的更优值支配旧候选

求每个长度k窗口的最大值。新值更大或相等时，旧候选更差且更早过期，之后不会再成为必要答案，可以从队尾淘汰。队首按下标检查过期，队列保持从大到小的候选值；求最小值反转比较方向。

{{fixed-extreme}}

这里保存的是**候选下标，不是排序后的整个窗口**。等值时可以保留较新的下标；旧下标移出窗口时不能凭值误删新的同值候选。`{2,2,3}`、k=2的最小值应为`{2,2}`。每个下标至多入队、出队一次，总时间O(n)，除输出外空间O(k)。

### 含负数的最短阈值段：队列维护历史前缀，而非原元素

目标是最短非空段满足`p[r]-p[l]>=target`。负数使普通窗口失去方向性，但可以证明两种历史候选可永久删除：

- 某个l已与当前r配成合法段，同一起点配更晚终点只会更长，记录后可删。
- 新起点j比旧起点i晚，且`p[j]<=p[i]`，则对所有未来右端，j得到的和不更小、长度却更短，i被支配。

{{signed-shortest}}

队列的下标递增，前缀值也递增。队首反复取出已经满足阈值的起点，以免只记录一个较长答案；队尾删除被新前缀支配的候选。当前r最后才入队，保证不是拿同一个前缀与自己组成空段。本接口无解返回0；原题若规定-1，对无解返回值作对应转换。

两种单调队列不能混用弹出理由：固定极值的队首因为**下标过期**删除；本题的队首因为**已经产生该起点最短可用答案**删除。时间O(n)、空间O(n)，前缀值与差均使用64位。

## 范围与原题参照

本章主讲一维序列的连续片段、静态前缀关系与窗口状态。一般排序、任意位置的k-sum、二维矩形、动态区间更新、窗口中位数／排名与代价不由本章外壳自动覆盖。

原题可对照[CSES区间和](https://cses.fi/problemset/task/1646/)、[正数和计数](https://cses.fi/problemset/task/1660/)、[有符号和计数](https://cses.fi/problemset/task/1661/)、[不同值限制](https://cses.fi/problemset/task/2428/)，以及LeetCode的[最短覆盖](https://leetcode.com/problems/minimum-window-substring/)、[替换预算](https://leetcode.com/problems/longest-repeating-character-replacement/)、[正整数乘积](https://leetcode.com/problems/subarray-product-less-than-k/)、[负数最短阈值段](https://leetcode.com/problems/shortest-subarray-with-sum-at-least-k/)。方法还参考了EPI的连续覆盖／无重复问题、CP4的最大段和与滑动窗口、Codility官方前缀与Caterpillar讲义；代码按本章合同独立编写。

CSES的部分固定窗口题采用很大的生成式输入，并要求将各窗口结果再做异或聚合；以上是相应区间内核，原题的生成、聚合和存储策略仍须按其约束处理，不能把返回所有结果的接口误认为完整提交。
