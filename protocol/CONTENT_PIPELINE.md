# 内容研究与建设协议

本协议是第二算法的内容工作权威入口。目标是为求职上机题建立可持续扩张的题型与算法基座，并将研究转化为可直接查阅的中文讲解与 C++ 参考代码。协议要求真实内容与实际结果，不要求固定来源数量、固定研究轮数、固定字数或复杂文书。

## 范围与完成的含义

正式范围围绕算法上机题、必要数据结构、方法变种、复杂度与实现条件。用户具有计算机本硕背景；本项目不负责语言基础课、英语、机器学习原理或系统设计面试。题库难度标签和社区热度可作线索，不能独自决定纳入与排除，也不能冒充目标岗位的出现概率。

范围是可版本化的研究结果，不是开工时随手列出的章节目录。初始入口可以覆盖排序与搜索、数组链表、栈队列与堆、哈希、双指针与窗口、前缀和与差分、回溯、贪心、动态规划、树图、字符串、位运算与数学；材料中发现的结构仍须独立判断，不能因没有旧目录位置而消失。

完成状态必须说明对应的范围与来源版本。可以核对某个指定清单是否逐项处理，以及已经纳入的模式是否有真实承载；不能证明整个互联网或未来招聘题目零遗漏，不编造全网覆盖率。发现新的相关模式、重要条件或外部反查失配时，重新打开受影响的内容缺口。

## 来源池与材料

`catalog/sources.json` 是来源池权威。每个来源要交代用途、原始入口、语言、出处关系及实际观察；同一网站的学习计划、方法目录、题目正文和源仓库可以是不同入口。核查围绕具体入口和范围进行，不能用一个网站级 verified 标签代表全站已读。

分别保存以下事实：来源是否采用、入口是否真正可读、清单是否完整取得、哪些正文实际读取、哪些候选已分析以及哪些模式已有正文和代码。页面只返回简介、执行只检查了部分结果、或列表仍有分页，都如实保留，不能改写为“无相关内容”或“全量完成”。

来源角色各有边界：原题用于核对目标与约束，方法资料用于理解算法，社区整理用于发现别名与替代观点，教材用于系统研究。官方原题不自动认证某份解法，转载数量不代表独立证据数量。保存镜像、翻译与上游关系，不把同题复制件重复计算为新问题。

书籍优先选择落实到具体题目与实现的实战资料，按目录与相关章节实际读取。用户提供的原件保留本机，公共仓库只保存允许公开的元数据、定位、原创研究与必要引用，不上传付费书籍、商业题库全文或个人旧手册原件。

材料使用已取得版本及实际读取范围。读取失败不能证明内容不存在。摘要可固定字节身份，不能证明模型读过或理解正确；只下载原件、只看到标题或只记录链接，均不能升级为正文已读。

## 发现与检索

研究组合使用四条路径：选定目录完整枚举；按算法名、目标、关键约束、组合方法及中英文别名查询；沿读件中的关联题、前置与替代方法扩展；从未参与目录构建的材料反向检查现有分类。

每个枚举任务要明确入口、范围、筛选与分页。结果中保留外部稳定身份及出处；目录枚举与正文阅读分开。相关和不明确的候选需继续读取题干及约束；明显不相关的组可按有理由的范围规则处理，不为每个条目复制相同文书。

查询计划与实际执行记录分开。保存真正使用的查询、入口、限制、取得范围与重要发现；不逐命令制造无价值日志，也不把计划中的查询列为已执行。用于校准搜索词的已知案例不能重复充当独立挑战证据。

增加来源是常规研究动作：先核查实际入口与用途，进入候选或采用池，按现有结构保留其取得方式与未知项。没有自动适配器的来源可以手动读取和登记，不虚构自动全量能力。新增付费、账号授权或后台定时活动不因加入来源池而自动获得授权。

## 归并与内容去向

题目身份、算法模式与阅读章节分开。不同题目共用方法时保留各自原题与条件，只归并教学内容；同题的翻译或镜像保留同源关系。一个模式有一个主要讲解位置，同时可以从多个相关专题定位。

归并必须比较目标变换、成立条件、核心判定和实现差异。相同外层循环不能证明同型；正负数、重复元素、连续与不连续、静态与动态、恰好与至多等条件可能改变整个算法。凡改变识别、正确性依据或实现的差异，均应有去向；不生成无依据的条件笛卡尔积。

已分析候选的去向可以是已有模式的佐证、局部变种、新模式、其他专题实际承载或明确排除；尚不能判断的保留待定。用足以恢复判断的简短理由说明，不强迫逐句建立断言台账。跨章目标不存在或尚未讲清时，仍是缺口，不能仅填一个专题名就算完成。

## 作者稿与参考代码

正文围绕题型条件、关键思路、相邻 C++ 代码和必要变种组织。保留决定比较、计数、状态转移或区间更新的解释；避免完整基础课，也避免把解释和代码拆成需要远距离拼接的索引。表格服务于局部对照，不取代连续、清楚的说明。

每份正文与代码保持一个权威版本。阅读版从作者稿及同一份源码装配；代码块与源码对应，重要修改后重新核对受影响题型。复杂度要结合原题规模和前提判断，不以编译成功代替算法正确。

验证选择能检验真实风险的办法，例如与独立枚举、排序合并、已知正确结果对比，或构造能区分关键条件的反例。不为可逆小改动制造大量镜像测试；历史测试通过与本次实际运行结果分开报告。

## 审阅与封存

内容准备封存时，回到范围与实际材料核对：指定候选是否有去向，纳入模式是否真正讲清，重要条件与变种是否保留，代码和正文是否一致，关联章节是否存在。再从外部案例独立分析，检查当前分类是否遗漏或硬套，并审阅读者能否顺畅定位和理解。

外部挑战的独立只指未参与本轮目录构建，不声称模型训练中从未见过。挑战用于修订以后转为建设材料，不能继续宣称仍是保留挑战。材料不足或仍有新模式出现就继续研究；不以固定几轮、固定候选数或“字段全部绿色”结束。

封存绑定范围、来源材料、记录、正文与代码版本。只报告有实际分母的处理进度；它不是全网召回率、学习效果或面试通过率。当前二分试章保持草稿及已知遗漏，不因导入仓库、CI 通过或重新构建而升级为完整章。

## 工程与恢复

工具负责确定性枚举、缓存、规范化、身份和引用核对、候选去重提示、缺口报告、代码装配与构建。语义相关性、模式归并、算法判断和阅读质量仍由模型实际完成。工具可以拒绝结构缺失，不能自动认证语义正确。

保留清单快照与成功基线；新获取失败记录为本次失败，不以空结果覆盖 last-good，不清空历史题目。新快照不再出现某个身份时保留历史及本次差异，不自动删除内容或排除题目。

中断后恢复同一任务的实际材料、研究结论、权威稿与具体下一步，不默认重新全网搜索或重写全文。具体恢复位置与操作见 [docs/RECOVERY.md](../docs/RECOVERY.md)；物理组织及模块分工见 [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md)。这些文档解释工程，不另立内容语义权威。

所有新增实际数据、缓存、下载、编译产物与本地教材由 D 盘承担。公共仓库不保存凭据、个人路径和不应外发的原件；索引和报告是可重建派生物，不与来源记录、作者稿形成第二套权威。
