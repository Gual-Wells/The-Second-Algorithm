# 本地教材材料约定

用户提供的完整教材保存在 D 盘工作区的 `.local/library/`，受 Git 忽略。用户原件保持只读，不移动、不改写、不删除。仓库公开书目只记录实际版本和质量摘要，不暴露私人路径、原始下载名称或完整正文。

## 原件与检索层

每份采用材料保留原件摘要、真实卷册与版本、目录和页码／spine定位、提取方式及质量疑点。采用副本与用户原件核对摘要；相同版本的视觉主件、OCR伴随件、合卷与独立卷要明确关系，不能当作多份独立内容。

页级文字用于查找和定位，章节索引用于按明确范围读取相关材料。代码、公式、表格和图示需要保留原页或坐标；不能只凭线性文本判定它们已正确还原。未经语义校对的提取层不标为“教材已全部读懂”或“代码可直接执行”。

## 本轮采用规则

- **CP4**：采用两个独立原生文字卷，Book 1为329物理页、Book 2为352物理页，共681页、279项目录。卷内说明对应2020年原内容，不把2022年PDF创建日期当成改写版；避免重复导入合卷。定位以“卷号＋物理页”为主，印刷页码可附记，不能跨卷仅凭印刷页码作唯一身份。错误的ToUnicode映射已根据原PDF明确字形名称在提取层修正，保留原始提取、修正依据和字形坐标，未改写PDF。Book 2物理55、258页的特殊大括号组件待核；分数、上下标、矩阵等二维公式及图表仍需结合坐标或原件页面。
- **EPI C++**：采用实际核实的 2015、Version 2.0.0、C++／C++11版本，共530物理页，已建立页级定位和25章目录索引。视觉图像件为权威，带现成OCR的同版副本只用于检索定位；未重新OCR。OCR程序符号不可信，引用与改编代码、解释公式和表格时回到原图。
- **Professional C++ 6e**：两份均为2024第6版，采用1379页原版式PDF，1970页重排本不重复复制。34章、1426书签、34个章后Exercises入口及物理／印刷页映射可检索；练习区数不是独立题数。默认plain文字；原始plain／layout和原页保留，layout假空格、跨页代码等需回原件核对。
- **The Modern C++ Challenge**：采用完整2018 EPUB为语义主件，321页PDF为视觉／页码伴随；另一EPUB的第79–100题解后部截断，已排除。100题及100份解答、12章、316个PRE块和图资源可按题读取；HTML实体、BR换行及缩进已对原PRE独立核对，没有替原书修复语义或勘误。
- **Discovering Modern C++ 2e**：版权2022；采用文件为1898页重排PDF，正文与索引1–816，之后为代码图像附录。1081个图像页通过原PDF反向链接关联正文；不当作额外题或正文工作量，不重新OCR。原件失效的临时URI不执行，查询层给出可回看的本地PDF页。
- **Modern C++ Programming Cookbook 2e**：2020年9月、ISBN9781800208988，751物理页、12章、712书签、132个食谱级条目。原始文字与读取层分开，重复页脚仅在读取层精确移除。C++20相关示例存在外部库依赖，不混成第3版C++23材料；第3版未取得不阻塞研究。
- **误标与不完整文件**：两个名称相似的 EPUB 实际是 Python 样章，不作为完整 C++ 基座；缺页或较差扫描件只保留鉴别关系，不混进权威教材集。

具体本地采用路径、摘要、目录与抽检记录由各材料包的 `manifest.json` 和 README 指向。公开 `catalog/books.json` 中的取得状态只说明材料已提供；实际已读章节与语义审阅仍需在内容任务中单独记录。

新C++材料的本地键为`professional-cpp`、`modern-cpp-challenge`、`discovering-modern-cpp`、`modern-cpp-cookbook`，分别对应`.local/library/<键>/`；总入口为该本地目录的README。各包自带按章／节／题／页的读取与检索脚本，结果保留实际范围和视觉定位。四种材料均未重新OCR，也未声称全书代码通过编译；取得与实际抽检见[入库记录](../research/2026-10-26/cpp-material-intake.md)。

## 进入内容工作

先按专题和相关目录选择完整材料，读取问题条件、解法论证、实现与必要交叉引用，再映射到案例、模式和条目。补读新增材料时只重开受影响的内容，不能靠更换材料摘要把旧作者稿假装成已复核。

版本鉴别、可检索预处理、内容研究与最终讲解是不同工作。已有页级文件无需每次重提全书；原始提取、纠正记录和原件相互可回查。
