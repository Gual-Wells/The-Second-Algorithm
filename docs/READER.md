# 第二算法阅读器

正式入口：https://second-algorithm.pages.dev/ 。iPhone PWA与电脑浏览器承载同一完整算法章；最新用户要求直接移植第二语言现行作品，而非另做同系候选。实际源、职责与兼容规则见`web/DESIGN.md`，逐项映射见`work/language-replica-20261029/source-map.md`。实现、准备包、成功部署和用户实际验收分别记录。

## 当前读者路线

标题栏沿源元信息、中文名、英文小标和原点读位置的独立Logo；上一节、下一节、章节答疑、设置单独一行。保留源日期/七日条与章节册/日历，普通选章直接正文首，前后章与七日条可续读，不再经过从头/继续/目录中转页。

本章旧目录、桌面侧栏和自造底部节导航取消。篇节索引位于源正文工具条位置，使用词条索引式两列筛选列表，完整H2/H3/H4可达，点击关闭后稳定跳转。底部为源薄状态条：真实同步/离线、当前H2节序和名称，非掌握率或导航按钮。源英语三栏、音频/译文及考试业务不引入。

正文章头、节带、文字、表格、设置及详情、知识、文件、手动答疑、安装与启动各态都按源角色的结构/比例/材质适配；C++保持原生选文、独立字号、复制、横滚及可选折行。源历史禁缩放不复制。所有原教材、CPP、知识、标题格式、锚点与日期身份不变。

纯净保留同一正文和纸宽；页头/日期/章头持续隐藏，轻触空白只短暂唤出原篇节索引条与状态条。双击安全阅读空白进出，代码/表格/控件、原生选择和缩放优先。打开/关闭知识和各窗口回原文字与焦点，键盘和短视口可用。

## 教材与唯一权威

一章对应代表性大算法思想，主结构只有理论前置和正式题型节；原PRE/中文节序、二级`（1）类型：具体内容`、三级`（a）类型：具体内容`及Hcode/Scode保持。完整标题树是编纂/验证内部结构，读者通过篇节索引访问，不恢复已取消的TOC。章节册里的“章节目录/日历”是全册浏览，继续沿源保留。

问题、推理、双实现、必要工程知识和练习仍在原题型位置；不靠前端文件数量或索引节点数量推断覆盖。C++知识只有一份完整权威，内部Q编号不显示，首次就近讲解、后续技术名称开窗复用，新场景推理仍在正文。研究/作者分工、验证和发布过程不写成学习内容。

日期唯一登记`carrier/chapter-calendar.json`，出版对象/顺序仍在`carrier/publications.json`；日期不改正文revision，不新增每日自动出章，同日可多章。规则见`protocol/CHAPTER_DATES.md`。

## 真实状态与保护

当前手动章节答疑未接处理transport：打开就说明，草稿按owner/章/版本保存，发送状态与能力一致，不假报受理、回复或红点。正式处理服务须另实做，复制聊天界面不代表后台完成。

旧notes/journal只读保全，不重新展示、自动同步、改写或删除；未同步原件继续保护退出清理。读位、历史、草稿和离线缓存按owner/document/revision隔离，慢旧请求与保存队列不覆盖新章；锁定后同页重新认证仍可恢复。首次加载在独立状态卡与白纸内开章卡之间真实交接，失败可重试，慢切章保旧文。

正文、知识、CPP与Markdown仍是受保护静态资产，公开壳只有必要版本白名单和标题元数据。新资源等真实SW控制器VERSION，不把update调用完成当接管；丢失VERSION答复的有界恢复仍守原总期限。更新不自动重载清编辑，401/403不读旧私人缓存。PWA原图标与alpha基线不改，新增透明页头Logo可离线使用。
