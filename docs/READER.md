# 算法思想与题型阅读器

入口 https://second-algorithm.pages.dev/ ，iPhone PWA和电脑浏览器共用蓝银系列主题。一个算法实战课程，无独立C++册、分轨章号或旧trial兼容。内容语义以CHAPTER_STANDARD为准，不能由代码块数、知识数或文件数推定学习范围。

## 思想、题型与知识

章由代表性大算法思想统领，主结构只有前置节与正式题型节，先思想/机制/条件/版图，再按题型由标准到复杂变型。证明、实现、方法选择回查和C++支撑归入相关节；四篇、作者分工和独立章末地图都不能抢占主导航。正式章只有一个逻辑读件，内部多稿按composition装配为实际节序，读者无需感知物理分工。2026-10-28曾撤回清零，后续已有第一章“二分”；实际线上状态查当前publication、quality与部署收据，不从历史初始化说明推断空站。

作者稿、权威cpp与独立知识源构建为受保护静态读件。原书、研究缓存、未发布稿和凭据不打包；D1只承载身份与私人状态。显式withdrawn没有正文/知识出口，私人笔记仍保留；新版本接管后只允许当前出版资源。

正文、知识、目录/搜索、代码注释与下载件都面向读者；作者分工、验证/OJ状态、改稿或发布过程留在内部记录。真实算法限制、设施职责和C++工程知识仍在对应教学位置。完整CPP下载保留编译所需上下文，仅去除明确的BEGIN/END制作标记；内部传输身份不作为可见教学编号。最终表面既须构建检查，也须当前人工`readerBoundary`审阅，二者都不自动证明学习效果。

C++知识内部身份不出现在读者标题、目录、按钮或链接文字。首次需要处可就近完整讲解；后续技术名称点击浮窗读取同一权威，可定位精确小节及前置知识，不离开原阅读位置。正文仍解释当前条件变化，链接不替代本题推理。不设要求读者管理编号的Q目录或单独C++课程。

浮窗使用既有蓝银sheet体系：打开不移动原文，关闭回到触发术语/读位，卡内前置可返回，不无限叠窗。知识有可独立随依赖出版的资产身份，最早主讲章撤回不自动删除仍被引用知识。具体离线依赖和交互实测以当次构建/验证记录为准，不能由协议文字宣称实机通过。

## 阅读与私人记录

正文/代码独立字号，代码保留原生选文/横滚/复制/可选换行，宽表内部横滚。复制局部代码和下载完整参考cpp用途分开，不冒称后者可直接提交任意平台。纯净模式保纸宽与排版，代码/表格/控件手势优先。

每篇读位按锚点和偏移/比例保存；章节/稿件切换续读，慢请求不覆盖新选择。知识浮窗不应写坏正文进度。笔记本机先存、联网同步，冲突保两稿，未同步状态不能被退出清空；本机数据可能被系统回收，不当永久备份。

离线按已验证owner隔离，只缓存当前白名单，auth/api不缓存，401/403不离线回退。新页面等实际Service Worker接管后才读取其版本资源，更新不自动打断编辑。模拟视口与真实iPhone安装/触控/图标验证分别报告。

## 构建和发布

```sh
npm run build:content
npm run check
python -m second_algorithm course quality
python -m second_algorithm research prepare-release <job>
npm run deploy -- --release work/jobs/<job>/releases/<id>.json
```

prepare须有符合当前硬协议的章级采用、真实研究/审阅和成功verify；旧专题的缺口不能被工程通过覆盖。deploy核当前包、锁和独立artifact，上传后核匿名保护/版本并保存收据。详见TASK_EXECUTION。无新知识数据库、周期轮询、生成API或订阅；本机新增数据实际存D。
