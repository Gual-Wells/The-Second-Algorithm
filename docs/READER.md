# 统一实战阅读器

入口为 https://second-algorithm.pages.dev/ ，iPhone PWA与电脑浏览器共用一套阅读语义和蓝银系列主题。有效内容由schema2出版登记和learning关系产生，不再有算法/C++两个track、独立章号或旧trial兼容。

## 内容与Q

章节按统一顺序呈现，一章可以多篇；当前仅登记practice-foundations。作者稿和cpp由handbook装配，carrier核对源码/显示代码/链接/摘要，输出受保护静态正文与源码。原书、研究缓存、凭据和未发布稿不打包。公开仓库保存原创稿，站点保护站内入口与私人状态。

全局Q索引只显示编号、标题与到唯一完整主讲的链接；后续引用不复述。正文编号跳转、同篇/跨篇跳转及浏览器返回恢复各自读位。Q有解释、测试通过、读过和掌握是不同事实。读者搜索按当前已发布正文/标题分段，诚实显示未下载或请求失败的范围。

## 阅读与记录

正文/代码独立字号、代码原生选择/横滚/复制/换行，宽表自行横滚，不挤出整页。代码片段复制与整份参考cpp下载有明确不同用途，不声称整份代码可直接提交任意平台。纯净模式不改变纸宽，代码/表格/控件手势优先。

每篇读位有内容锚点及偏移/比例。章节多稿导航和最近续读按当前登记，慢加载不让迟到请求覆盖新选择。笔记本机先存、联网同步，活动页面有独立待保存槽，冲突保留两稿；未同步状态不能悄悄被退出清空。浏览器本机数据可能被系统回收，不是永久备份。

离线缓存以经服务端验证的owner隔离，只缓存当前构建白名单，auth/api不缓存，401/403不离线回退。新页面等实际SW接管后才取其版本内容；更新不自动打断编辑。只有模拟浏览器检查不能称iPhone真机安装已验收。

## 构建与发布

```sh
npm run build:content
npm run check
python -m second_algorithm research prepare-release <job>
npm run deploy -- --release work/jobs/<job>/releases/<id>.json
```

prepare之前须有当前真实研究/独立审阅证据与成功research verify，详见TASK_EXECUTION。deploy使用独立UUID staging的完整artifact，避免并行检查替换共享dist；前后核验包、串行部署，上传后检查匿名保护和固定artifact的SW build，另存部署记录。

D1仅身份/会话/私人状态；静态正文与源码不入D1，没有新增内容数据库、周期轮询、AI调用或付费订阅。本机依赖/缓存/TEMP/TMP/日志/QA/构建全存D，不修改共享依赖联接目标。
